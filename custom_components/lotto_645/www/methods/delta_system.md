# 공개 공식 · 델타 시스템

[23개 공식 목록](../../README.md#추첨-공식-23종) · [공통 계산 원리](../FORMULAS.md)

`method_id: delta_system` · 분류: 공개 분석식 · 후보 풀: **24개**

## 1. 어떤 공식인가요?

오름차순 번호 자체보다 **첫 번호와 인접 번호 사이의 차이**를 평가합니다. 간격이 과하게 크거나 같은 차이가 반복되는 형태를 조합 점수에 반영합니다.

번호별 빈도 특징으로 후보 풀을 구성한 뒤 델타 점수를 사용하는 구조입니다. 델타 숫자만 무작위로 만들고 누적합으로 추천을 생성하는 공식은 아닙니다.

## 2. 사용하는 데이터와 계산

오름차순 6개 번호를 `x1...x6`이라 하면 델타는 다음 **6개**입니다.

```text
d = [x1, x2-x1, x3-x2, x4-x3, x5-x4, x6-x5]
```

첫 번호도 델타에 포함되며, 마지막 번호에서 45까지 남은 거리는 포함하지 않습니다.

```text
A = 1~15인 델타 수 / 6
U = 서로 다른 델타 수 / 6
P = max(0,가장 많이 반복된 델타 횟수-2) / 4
M = max(0,1-abs(최대 델타-11)/18)
R = max(0,1-abs((최고번호-최저번호)-34)/30)
델타 점수 = max(0,0.42×A + 0.21×U + 0.18×M + 0.19×R - 0.20×P)
```

15·11·34와 각 분모·가중치는 고정 설계값입니다. 자동 학습한 최적값이나 당첨 공식으로 검증된 숫자가 아닙니다.

## 3. 번호 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `long_neutral` | 장기 빈도 중립성 | 0.30 |
| `recent_neutral` | 최근 빈도 중립성 | 0.24 |
| `gap_balance` | 미출현 간격 균형 | 0.20 |
| `frequency_100` | 최근 100회 출현 강도 | 0.16 |
| `graph_strength` | 번호쌍 연결 요약 | 0.10 |

## 4. 조합 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `individual` | 선택 번호 점수 평균 | 0.66 |
| `pair` | 내부 번호쌍 연결 | 0.05 |
| `diversity` | 내부 변화 방향·간격 다양성 | 0.08 |
| `balance` | 조합 전체 형태 균형 | 0.12 |
| `delta` | 델타 크기·반복·범위 | 0.38 |

합계 1.29로 정규화한 뒤 공통 유사성 감점을 적용합니다. 델타가 15를 넘는다고 즉시 제외하는 강제 조건은 아닙니다.

## 5. 계산 예시

**가상 조합** `[3,11,20,28,35,44]`의 델타는 `[3,8,9,8,7,9]`입니다. 여섯 값이 모두 1~15이고, 서로 다른 값은 4개, 최대 반복 횟수는 2, 최대 델타는 9, 전체 번호 범위는 41입니다.

따라서 `A=1`, `U=4/6`, `P=0`, `M=8/9`, `R=23/30`이고 델타 요소 점수는 약 `0.865667`입니다. 이는 특정 실제 회차의 추천이나 최종 당첨 확률이 아닙니다.

## 6. 설정과 결과 확인

통합 **구성 → 추천 설정**에서 선택합니다. 사주정보나 AI는 필요하지 않습니다. 델타 목표값을 별도로 조절하는 사용자 옵션은 없습니다.

`score_components`의 `delta`와 `balance`, `score_component_weights`를 확인하세요. 일반 속성에 델타 배열이 따로 없는 경우, 표시된 오름차순 번호로 위 식처럼 직접 차이를 계산할 수 있습니다. `gaps_since_last`는 출현 사이의 **회차 간격**이므로 번호 차이인 델타와 다릅니다.

## 7. 차이와 해석의 한계

[균형 필터](balance_formula.md)는 합계·홀짝·저고 등 전반적 모양을, 이 공식은 번호 사이 간격의 모양을 더 봅니다. 두 공식 모두 무작위 추첨에 기억이나 규칙성을 부여하지 않습니다.

일정한 모양의 후보를 선호하는 도구이며, 델타 점수가 높은 특정 조합의 1등 확률이 더 높은 것은 아닙니다. 여러 조건을 만족했다는 이유로 당첨 보장으로 해석하지 마세요.
