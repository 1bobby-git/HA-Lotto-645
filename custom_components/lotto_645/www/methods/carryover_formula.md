# 공개 공식 · 이월수

[추첨 공식 목록](../../README.md#추첨-공식-19종) · [공통 계산 원리](../FORMULAS.md)

`method_id: carryover_formula` · 분류: 공개 분석식 · 후보 풀: **22개**

## 1. 어떤 공식인가요?

직전 회차의 본번호가 다음 조합에 몇 개 포함되는지, 즉 **이월 개수**를 평가합니다. 특정 직전 번호의 재출현을 확신하는 공식이 아니라 두 6개 집합의 겹침 개수 분포를 점수로 사용합니다.

과거 통계에서 1개·2개 이월 비중을 학습하는 것이 아니라, 45개 중 6개를 고르는 이론적 초기하분포를 고정 사용합니다.

## 2. 사용하는 데이터와 계산

직전 본번호 집합을 `L`, 후보 조합을 `C`, 겹친 수를 `k=|L∩C|`라 하면:

```text
P(k) = C(6,k) × C(39,6-k) / C(45,6)
이월 조합점수 = P(k) / max(P(0),...,P(6))
```

`C(a,b)`는 조합 수입니다. 이론적 값은 다음과 같습니다. 이는 **이월 개수 범주 전체의 비중**이지 특정 복권 한 장의 당첨 확률이 아닙니다.

| 이월 개수 | 이론적 비중(%) | 이월 요소 점수(약) |
|---|---|---|
| 0개 | 40.05646367 | 0.944444444 |
| 1개 | 42.41272624 | 1.000000000 |
| 2개 | 15.14740223 | 0.357142857 |
| 3개 | 2.24405959 | 0.052910053 |
| 4개 | 0.13646308 | 0.003217503 |
| 5개 | 0.00287291 | 0.000067737 |
| 6개 | 0.00001228 | 0.000000289 |

따라서 현재 구현의 이월 요소 점수는 **1개 → 0개 → 2개 → 3개...** 순서입니다. ‘1개 다음으로 2개를 가장 높게 평가한다’는 설명과 다릅니다. 6개 이월 조합은 직전 1등 본번호와 완전히 같으므로 실제 후보 선택에서는 공통 제외 규칙에 걸립니다.

## 3. 번호 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `transition` | 직전 번호 기반 다음 회차 전이 | 0.34 |
| `frequency_30` | 최근 30회 출현 강도 | 0.23 |
| `gap_balance` | 간격 균형 | 0.18 |
| `graph_strength` | 번호쌍 연결 요약 | 0.15 |
| `long_neutral` | 장기 빈도 중립성 | 0.10 |

## 4. 조합 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `individual` | 선택 번호 점수 평균 | 0.66 |
| `pair` | 내부 번호쌍 연결 | 0.10 |
| `diversity` | 내부 변화 방향·간격 다양성 | 0.05 |
| `balance` | 조합 형태 균형 | 0.08 |
| `carryover` | 이론 분포로 평가한 겹침 수 | 0.34 |

합계 1.23으로 정규화합니다. 별도 공통 감점에서 직전 겹침 1개당 0.007을 빼며, 이는 이월 조합 가중치가 없는 공식의 0.023보다 작습니다. 반복 4개·5개 부분집합 감점은 그대로 적용됩니다.

## 5. 계산 예시

직전 본번호를 `[1,2,3,4,5,6]`이라고 **가정**하면 후보 `[1,10,20,30,40,45]`는 이월 1개, 후보 `[10,11,20,30,40,45]`는 이월 0개입니다. 이월 요소만 보면 각각 1과 약 0.9444를 받습니다.

다른 번호·조합 요소와 감점까지 합치면 이월 0개 후보가 최종적으로 더 높을 수도 있습니다. 특정 번호를 추천한 예시가 아니라 겹침 개수 계산 예시입니다.

## 6. 설정과 결과 확인

통합 **구성 → 추천 설정**에서 선택합니다. 원하는 이월 개수를 직접 지정하는 옵션은 없습니다.

`carryover_count`, `latest_draw_overlap`, `score_components`의 `carryover`와 `historical_similarity_penalty`를 확인하세요. 직전 회차를 올바르게 이해하려면 실제 분석 기준 회차도 함께 확인해야 합니다.

## 7. 차이와 해석의 한계

[전이·간격 위상](transition_gap_phase.md)은 번호별 다음 회차 관계를, 이 공식은 조합에 포함되는 직전 번호의 개수도 직접 평가합니다. [종합 앙상블](public_ensemble.md)도 같은 이월 요소를 쓰지만 그 추가 가중치는 더 작습니다.

42.41%는 ‘직전과 1개 겹치는 모든 가능한 다음 조합’의 비중입니다. 1개 겹치도록 고른 특정 한 조합의 1등 확률이 42.41%라는 뜻은 아닙니다. `score`는 당첨 확률이 아닙니다.
