# 명리 권장 · 개인 사주 원국·대운·추첨일

[추첨 공식 목록](../../README.md#추첨-공식-24종) · [공통 계산 원리](../FORMULAS.md) · [명리 규칙 상세](../SAJU_RULES.md)

`method_id: myungri_hetu_day_pillar` · 분류: 개인 사주 명리 권장 · 후보 풀: **22개**

## 1. 어떤 공식인가요?

사용자가 직접 입력한 출생정보로 개인 사주 원국과 운의 관계를 계산하고, 다음 추첨 예정일의 사주와 비교하여 번호 선택에 반영합니다. 번호의 오행·음양·십신 배속과 가중치 합산은 **현대적 응용 휴리스틱**입니다.

내부 ID에 `day_pillar`가 남아 있지만 현재 기능은 추첨일 일진만으로 추천하는 공식이 아닙니다. 기존 설정 호환성을 위해 ID를 유지한 것이며 **개인 사주정보를 저장하지 않으면 이 공식은 활성화되지 않습니다.** 기본 선택에도 포함되지 않습니다.

## 2. 먼저 입력할 정보

**설정 → 기기 및 서비스 → Lotto 6/45 Analysis → 구성 → 명리 사주정보 입력·수정**에서 프로필을 먼저 저장합니다. 그다음 추천 설정에서 이 공식을 선택합니다.

| 항목 | 입력과 처리 |
|---|---|
| 양력/음력 | 실제 출생기록 기준으로 선택 |
| 생년월일 | `YYYY-MM-DD` 또는 `YYYYMMDD`; 존재하는 날짜를 검증 |
| 출생시간 | `HH:MM`, `HHMM` 또는 `미상` |
| 성별 | 현재 구현의 대운 순역 계산에 사용할 선택값 |
| 출생지 | 사용자가 직접 입력. 입력 문자열만으로 위치·경도를 자동 추정하지 않음 |
| 시간대 | 출생지의 IANA 시간대. 한국 출생 예: `Asia/Seoul` |
| 음력 기준·윤달 | 한국/중국 음력 기준과 실제 윤달 여부를 명시 |
| 진태양시·경도 | 선택 기능. 켜면 확정된 출생시간과 -180~180의 유한한 경도가 필요 |

지원 출생연도 검사 범위는 1900~2050이며, 범위 안이어도 현재보다 미래인 출생일·존재하지 않는 날짜·음력 변환 실패는 거부합니다. 출생시간 미상일 때 시주를 만들어내지 않습니다. 절입 경계일처럼 시간 없이는 연·월주를 확정할 수 없는 경우에는 입력 검증에서 중단할 수 있습니다. 서머타임으로 존재하지 않거나 중복되는 현지 시각도 임의로 결정하지 않습니다.

기존 음력 프로필의 중국력 기준을 사용자 승인 없이 한국력으로 자동 변경하지 않습니다. 시간 미상 상태에서는 진태양시 보정을 켤 수 없습니다. 이 설정들은 정확한 입력 해석을 위한 것이지 당첨 예측을 강화한다고 검증된 옵션이 아닙니다.

## 3. 개인 사주에서 번호 특징까지

원국의 연·월·일·시주(시각 미상 시 시주 제외), 월령·통근·투간·지장간 비율·십신 분포·격국 후보를 계산합니다. 억부·조후·통관·병약을 바탕으로 보완오행 후보를 만들고 대운·세운·월운·일운·시운의 관계를 적용합니다.

추첨 기준 시각은 **마지막 공식 추첨일 + 7일, 한국시간 20:35**라는 코드상의 예정 시각 가정입니다. 실제 공이 추출된 순간을 측정한 시각이 아닙니다. 비정상 날짜나 출생 이전 대상 회차는 검증 대상입니다.

번호 끝자리는 다음 오행에 배속합니다.

| 끝자리 | 오행 |
|---|---|
| 1·6 | 수 |
| 2·7 | 화 |
| 3·8 | 목 |
| 4·9 | 금 |
| 5·0 | 토 |

홀수는 양, 짝수는 음의 응용 배속을 사용하고 개인 일간과 번호 배속 천간의 관계로 십신을 구합니다. 예를 들어 1·11·21·31·41은 같은 수 오행 그룹이지만, 로또 통계 보조 특징까지 같다는 뜻은 아닙니다.

명리 내부 번호 점수는 **보완오행 0.40 + 십신분포 0.20 + 운계층 0.24 + 합충형파해 0.12 + 음양 0.04**로 구성됩니다. 운계층의 원시 비중은 대운 0.30, 세운 0.25, 월운 0.20, 일운 0.15, 시운 0.10이며 실제 존재하는 계층의 비중 합으로 정규화합니다. 이 명리 점수에는 다시 순위 변환을 하지 않습니다.

## 4. 번호 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `myungri_resonance` | 위의 개인 명리 내부 점수 | 0.72 |
| `graph_strength` | 로또 번호쌍 연결 요약 | 0.08 |
| `transition` | 로또 다음 회차 전이 | 0.07 |
| `gap_balance` | 로또 미출현 간격 균형 | 0.05 |
| `frequency_100` | 로또 최근 100회 출현 강도 | 0.04 |
| `long_neutral` | 로또 장기 빈도 중립성 | 0.04 |

72%는 번호 단계에서의 비중입니다. 최종 조합에는 다음 단계의 별도 명리 점수도 들어가므로 ‘전체 추천의 명리 비중이 정확히 72%’라고 보면 안 됩니다.

## 5. 조합 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `individual` | 선택 번호 점수 평균 | 0.66 |
| `pair` | 내부 번호쌍 연결 | 0.05 |
| `diversity` | 내부 변화 방향·간격 다양성 | 0.05 |
| `balance` | 일반 조합 형태 균형 | 0.06 |
| `myungri` | 명리 조합 적합도 | 0.52 |

합계 1.34로 정규화하고 공통 유사성 감점을 적용합니다. 명리 조합 적합도 자체는 명리 공명 평균 0.45, 보완오행 포함 비율 0.20, 오행 종류 분산 0.15, 홀짝 균형 0.10, 동일 오행 과집중 완화 0.10을 결합합니다.

## 6. 계산 예시

특정 번호의 **가상 명리 내부 요소**가 보완오행 0.8, 십신분포 0.5, 운계층 0.6, 합충형파해 0.5, 음양 0.55라면:

```text
명리 특징 = 0.40×0.8 + 0.20×0.5 + 0.24×0.6
            + 0.12×0.5 + 0.04×0.55 = 0.646
```

이 값이 `myungri_resonance`로 들어가며 여기에 로또 통계와 조합 보정이 추가됩니다. 사용자의 실제 생년월일을 가정하거나 특정인의 운세·당첨번호를 산출한 예시가 아닙니다. 0.646을 재물운·당첨 확률 64.6%로 해석해서는 안 됩니다.

## 7. 센서 속성과 개인정보

`명리 사주 프로필`에서 준비 상태를, 추천 센서에서 `four_pillars`, `day_master`, `day_master_strength`, `favorable_elements`, `structural_analysis`, `luck_layers`, `number_score_trace`, `calculation_warnings` 등 계산 근거를 확인합니다. 큰 상세 속성은 Recorder 중복 저장을 줄이도록 별도로 관리하므로 모든 과거 시점의 상세 속성이 Recorder에 남는다고 보장하지 않습니다.

원본 생년월일·출생시간·출생지는 로또 공유 미러와 HA AI 추천 프롬프트에 전달하지 않습니다. 그렇다고 공개 공유해도 되는 데이터는 아닙니다. HA의 설정·백업과 파생 사주 속성에도 개인 정보가 포함될 수 있으므로 로그·화면을 공유할 때 가리세요.

## 8. 해석의 한계와 다른 공식과의 관계

지장간 비율 등의 일부 규칙은 이 프로젝트가 채택한 학파·원문 기준이며 모든 학파가 일치하는 표준이 아닙니다. 합의 관찰은 합화의 확정이 아니며, 격국·보완오행 후보는 용신의 확정 판정이 아닙니다. 신살·납음·12운성 등 참고 분류를 당첨 가산점으로 단정하지 않습니다.

계산 재현성 검증과 사주 해석의 타당성, 로또 예측력은 서로 다른 문제입니다. 과학적으로 입증된 당첨 확률 향상을 주장하지 않습니다. 이 공식을 선택하면 [선택 공식 중앙값](selected_median_consensus.md)의 기여 공식에는 들어갈 수 있지만, [종합 앙상블](public_ensemble.md)의 고정 특징에는 명리가 추가되지 않습니다.
