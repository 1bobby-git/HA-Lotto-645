# 합의 추천 · 선택 공식 중앙값

[23개 공식 목록](../../README.md#추첨-공식-23종) · [공통 계산 원리](../FORMULAS.md)

`method_id: selected_median_consensus` · 분류: 선택 공식 집계 · 후보 풀: **26개**

## 1. 어떤 공식인가요?

사용자가 **함께 선택한 다른 로컬 공식의 1~45 번호별 적합도**를 모아 각 번호의 중앙값을 계산합니다. 특정 공식의 극단적인 점수가 전체 결과를 과하게 끌고 가지 않도록 하는 집계 공식입니다.

추천게임을 정렬한 뒤 첫 번째 번호끼리·두 번째 번호끼리 중앙값을 내는 계산이 아닙니다. 6개 번호 목록이 아니라 **각 공식이 내부에서 계산한 45개 번호 점수**가 입력입니다.

## 2. 선택 조건과 포함 범위

통합 **구성 → 추천 설정**에서 이 공식과 **다른 로컬 추첨 공식 2개 이상**을 함께 선택합니다. 즉 최소 총 3개 공식이 필요합니다. 조건을 만족하지 않으면 옵션 저장에서 안내하고 계산을 진행하지 않습니다.

Home Assistant AI는 집계 대상이 아니며, 최소 2개 조건에도 포함되지 않습니다. 개인 사주 공식은 프로필 입력을 완료하고 명시적으로 함께 선택했을 때만 들어갑니다. 기본 선택에는 중앙값 공식 자체가 포함되지 않습니다.

## 3. 번호별 계산과 가중치

기여 공식 `m`의 번호 `n` 적합도를 `S_m(n)`이라 하면:

```text
중앙값 점수(n) = median(S_1(n), S_2(n), ..., S_M(n))
점수 범위(n) = max(S_m(n)) - min(S_m(n))
```

기여 공식의 `S_m(n)`은 해당 공식의 번호 특징 가중 평균입니다. 그 공식의 최종 조합 보정점수나 과거 리뷰 별점을 사용하지 않습니다. 기여 공식은 동일하게 한 표본씩 참여하며 성적에 따른 가중치를 주지 않습니다.

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `selected_method_median` | 다른 선택 공식의 번호별 중앙값 | 1.00 |

위 키는 센서에 표시되는 동적 특징입니다. `methods.py`의 정적 `weights`는 비어 있고 `_prepare_selected_median`이 값을 준비합니다. 짝수 개의 기여 공식은 정렬한 가운데 두 값의 평균을 사용합니다. 기여 공식이 정확히 2개면 중앙값은 두 값의 평균이므로 극단값 완화 효과도 제한적입니다.

## 4. 조합 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `individual` | 선택 6개 번호의 중앙값 점수 평균 | 0.66 |

별도 번호쌍·삼중·균형·델타·이월·명리 조합 가중치는 모두 0입니다. 합계가 0.66이므로 정규화 후 `individual` 비중은 100%입니다. 하지만 과거 유사성 감점과 과거 1등·다른 공식 완전일치 제외는 여전히 적용됩니다.

중앙값 공식은 다른 공식의 최종 추천이 생성된 **뒤에 마지막으로 실행**됩니다. 후보 풀 26개에서 조합을 평가하므로 중앙값 상위 6개를 무조건 그대로 출력하지 않습니다.

## 5. 계산 예시

같은 후보 번호 A에 대해 세 공식의 **가상 적합도**가 `[0.20,0.70,0.90]`이면 중앙값은 0.70, 점수 범위는 0.70입니다. 네 공식이 `[0.20,0.60,0.80,0.90]`이면 중앙값은 `(0.60+0.80)/2=0.70`입니다.

기여 공식의 최종 6개 번호에 A가 실제 포함된 횟수는 별도의 **지지표 수**입니다. 내부 점수가 높아도 다른 조합 조건 때문에 그 공식의 최종 번호에 없을 수 있습니다. 따라서 중앙값 0.70과 지지표 0개가 동시에 나타나도 모순은 아닙니다.

이 예시는 실제 번호의 당첨 예측이나 과거 성적이 아닙니다. 중앙값 0.70을 70% 당첨 확률 또는 70% 공식이 선택했다는 비율로 읽지 마세요.

## 6. 센서 속성 읽기

| 속성 | 의미 |
|---|---|
| `consensus_source_method_ids` / `consensus_source_methods` | 기여 공식의 ID와 표시명 |
| `consensus_source_count` | 기여 공식 수. 중앙값 자신과 AI는 제외 |
| `consensus_number_median_scores` | 최종 선택된 번호들의 중앙값 적합도 |
| `consensus_number_score_spread` | 최종 번호의 기여 공식 간 최고-최저 점수 차이 |
| `consensus_number_support_votes` | 각 최종 번호가 기여 공식의 최종 추천에 포함된 횟수 |
| `number_feature_scores` | 최종 번호별 중앙값·점수 범위·지지표 |
| `score_components` | 번호 평균 및 공통 유사성 감점 |

**점수 범위와 지지표는 설명용 정보이며 현재 중앙값 최종 점수에 별도 가산·감점하지 않습니다.** 큰 점수 범위는 공식들의 평가가 갈린다는 뜻이지 불확실성의 통계적 신뢰구간은 아닙니다. 번호별 속성은 최종 선택 6개에 대해 노출됩니다.

## 7. 활용 시 차이와 한계

[종합 앙상블](public_ensemble.md)은 고정된 11개 특징을 결합하므로 혼자 선택해도 됩니다. 이 공식은 사용자의 기여 공식 선택에 따라 집계 입력 자체가 달라집니다.

같은 이력에서 파생된 공식들은 서로 비슷한 점수를 낼 수 있습니다. 비슷한 공식들을 여러 개 넣었다고 독립적 증거가 그만큼 늘어나는 것은 아닙니다. 기여 공식의 평균·중앙값은 확률 보정 모델이 아니므로 당첨 확률을 높인다는 보장이 없습니다.

설정을 바꾸거나 수동 재생성하면 다른 공식의 최종 번호와 공통 중복 제외가 달라져 중앙값 추천도 바뀔 수 있습니다. 과거 리뷰가 좋은 공식에 자동 가중치를 더하는 기능은 구현되어 있지 않습니다.
