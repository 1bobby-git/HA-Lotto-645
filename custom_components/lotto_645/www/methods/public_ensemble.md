# 복합 공식 · 공개 지표 종합

[추첨 공식 목록](../../README.md#추첨-공식-22종) · [공통 계산 원리](../FORMULAS.md)

`method_id: public_ensemble` · 분류: 공개 분석식 · 후보 풀: **24개**

## 1. 어떤 공식인가요?

빈도, 최근성, 베이지안 수축, 미출현, 전이와 동반출현을 번호 점수로 결합하고, 조합 단계에서 균형·델타·이월 등을 보정하는 **고정 다중 지표 공식**입니다.

다른 공식들이 이미 출력한 추천번호를 투표하는 구조가 아닙니다. 사용자가 함께 선택한 공식이 무엇이든 이 공식 자체의 특징·가중치는 같습니다. 다만 다른 선택 공식과의 중복 제외 때문에 최종 번호는 달라질 수 있습니다.

여러 지표를 조합하는 선호 공식이며, 다른 공식보다 성능이 우월한 권장안으로 표시하지 않습니다.

## 2. 사용하는 데이터와 계산

최근 10·30·100회 빈도, 반감기 20회의 최근 최대 260회 감쇠, 최근 최대 300회 (호환 키 이름 유지) 베이지안 수축, 전체·최근 120회 번호쌍, 전체·최근 180회 삼중 연결 등을 사용합니다. 미출현과 전이·장기 중립성도 포함합니다.

각 특징의 계산법은 [공통 안내](../FORMULAS.md)와 해당 개별 문서와 같습니다. AI나 개인 사주 점수는 이 앙상블에 포함되지 않습니다.

## 3. 번호 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `frequency_10` | 최근 10회 출현 강도 | 0.08 |
| `frequency_30` | 최근 30회 출현 강도 | 0.10 |
| `frequency_100` | 최근 100회 출현 강도 | 0.10 |
| `frequency_decay` | 지수감쇠 최근성 | 0.08 |
| `bayesian_60` | 베이지안 수축 특징 | 0.08 |
| `overdue_capped` | 상한을 둔 미출현 간격 | 0.08 |
| `transition` | 다음 회차 전이 | 0.10 |
| `graph_strength` | 번호쌍 연결 요약 | 0.12 |
| `triplet_strength` | 삼중 연결 요약 | 0.08 |
| `long_neutral` | 장기 빈도 중립성 | 0.04 |
| `gap_balance` | 간격 균형 | 0.04 |

**원시 가중치 합계는 0.90입니다.** 최종 번호 점수는 가중합을 0.90으로 나눕니다. 따라서 0.12는 약 13.33%, 0.10은 약 11.11%, 0.08은 약 8.89%, 0.04는 약 4.44%의 비중입니다. 표의 0.12를 최종 비중 12%로 읽지 마세요.

## 4. 조합 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `individual` | 선택 번호 점수 평균 | 0.66 |
| `pair` | 내부 번호쌍 연결 | 0.14 |
| `triplet` | 내부 삼중 연결 | 0.07 |
| `diversity` | 내부 변화 방향·간격 다양성 | 0.10 |
| `balance` | 조합 형태 균형 | 0.15 |
| `delta` | 델타 크기·반복·범위 | 0.11 |
| `carryover` | 직전 번호 겹침의 이론 분포 | 0.09 |

합계 1.32로 정규화하므로 번호 평균의 비중은 50%입니다. 이월 가중치가 있는 공식이므로 직전 겹침의 별도 감점 계수는 0.007을 사용합니다. 공통 과거 4개·5개 부분집합 감점과 완전일치 제외도 유지합니다.

## 5. 계산 예시

**가상으로** 모든 번호 특징값이 0.5이면 가중합은 `0.90×0.5=0.45`이지만 정규화된 번호 점수는 `0.45/0.90=0.5`입니다. 가중치 합이 1이 아니라고 점수가 자동으로 작아지는 것은 아닙니다.

같은 조건에서 `graph_strength`만 0.8이면 번호 점수는 `0.5+(0.12/0.90)×0.3=0.54`가 됩니다. 한 특징이 좋아져도 전체 점수가 과도하게 움직이지 않는 결합 구조를 보여 주는 예시이며 실제 특정 번호의 통계가 아닙니다.

## 6. 설정과 결과 확인

통합 **구성 → 추천 설정**에서 선택하며 기본 선택 5개에 포함됩니다. 이 앙상블만 선택해도 실행할 수 있습니다. 다른 공식 2개 이상을 요구하는 것은 [선택 공식 중앙값](selected_median_consensus.md)입니다.

`number_feature_weights`에서 정규화된 11개 비중, `number_feature_scores`에서 최종 번호별 지표, `score_component_weights`와 `score_components`에서 조합 점수와 감점을 확인하세요. 가중치는 코드 고정값이고 UI에서 자동 학습·개별 조절하지 않습니다.

## 7. 차이와 해석의 한계

[선택 공식 중앙값](selected_median_consensus.md)은 사용자가 선택한 다른 공식의 **번호 점수**를 집계합니다. 이 앙상블은 정해진 **원천 특징**을 고정 가중치로 결합합니다. 두 공식의 합의라는 표현은 같은 계산을 뜻하지 않습니다.

서로 겹치는 이력과 파생 특징을 여러 번 쓰므로 지표 수가 곧 독립된 증거의 수는 아닙니다. 여러 지표를 섞었다고 `score`가 당첨 확률로 바뀌거나 우연한 패턴이 사라지는 것은 아닙니다.
