# 독창 패턴 · 다중시간대 공명

> v1.15.0부터 새 생성에서 제외된 공식입니다. 이전 결과의 설명을 위해 이 문서를 보존합니다.

[추첨 공식 목록](../../README.md#추첨-공식-22종) · [공통 계산 원리](../FORMULAS.md)

`method_id: multiscale_resonance` · 분류: 독창 분석 · 후보 풀: **22개**

## 1. 어떤 공식인가요?

한 관찰 기간의 빈도만 따르지 않고 **30·120·260회와 전체 이력의 관계**를 여러 특징으로 표현해 결합합니다. 최근 변화의 크기, 변화의 굴곡, 장기와 단기의 방향 차이에 전이·번호쌍·간격을 더합니다.

‘공명’은 실제 주파수 분석이나 모든 신호가 같은 방향일 때만 통과하는 조건이 아닙니다. 서로 다른 특징의 가중 평균이라는 구현상의 이름입니다.

## 2. 사용하는 데이터와 계산

```text
변화 크기 = abs(z30-z120)
곡률 = abs((z30-z120)-(z120-z260))
반대 위상 = max(0,-z전체 × (z30-z120))
간격 균형 = -abs(gap_z)
```

이 값들을 45개 번호 안에서 순위화합니다. 전이는 직전 번호별 과거 다음 회차 관측, 그래프 강도는 전체·최근 120회 번호쌍의 강한 양의 연결을 이용합니다.

공통 엔진이 최근 10회 지표도 만들지만, **이 공식의 번호 점수에는 `frequency_10`이 직접 포함되지 않습니다.** 기간 목록과 실제 투입되는 특징을 구분해야 합니다.

## 3. 번호 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `phase_velocity` | 30회와 120회 잔차 차이의 크기 | 0.22 |
| `curvature` | 30·120·260회 변화 굴곡 | 0.19 |
| `counter_phase` | 장기·단기 반대 방향 | 0.18 |
| `transition` | 다음 회차 전이 | 0.16 |
| `graph_strength` | 강한 번호쌍 연결 요약 | 0.15 |
| `gap_balance` | 현재 간격의 중립성 | 0.10 |

## 4. 조합 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `individual` | 선택 번호 점수 평균 | 0.66 |
| `pair` | 내부 번호쌍 연결 | 0.16 |
| `diversity` | 내부 변화 방향·간격 다양성 | 0.13 |
| `balance` | 홀짝·저고·합·범위·구간의 균형 | 0.08 |

합계 1.03으로 정규화합니다. 균형은 보조 점수이며 ‘홀짝 3:3이 아니면 제외’ 같은 필수 조건이 아닙니다. 이후 공통 감점과 후보 제외를 적용합니다.

## 5. 계산 예시

특정 번호의 **이미 정규화된 가상 특징**을 표 순서대로 `0.8,0.6,0.7,0.5,0.4,0.9`라고 하면 번호 점수는:

```text
0.22×0.8 + 0.19×0.6 + 0.18×0.7
+ 0.16×0.5 + 0.15×0.4 + 0.10×0.9 = 0.646
```

변화 크기가 높아도 그래프 연결이 약하면 그만큼 평균점수에 반영됩니다. 0.646은 다음 회차 출현 확률 64.6%가 아니며 실제 이력으로 산출한 특정 번호의 결과도 아닙니다.

## 6. 설정과 결과 확인

통합 **구성 → 추천 설정**에서 선택합니다. 별도 사주정보나 AI는 필요하지 않습니다. 이 공식은 지원 목록에는 있지만 기본 선택 5개에는 포함되지 않습니다.

`number_feature_scores`의 여섯 특징, `phase_leaders`, `transition_leaders`, `score_components`의 `pair`, `diversity`, `balance`를 같이 읽으면 어떤 점수가 최종 조합을 지지했는지 확인할 수 있습니다. 기간·가중치는 일반 설정에서 조절하지 않습니다.

## 7. 차이와 해석의 한계

[위상잔차 그래프](phase_residual_graph.md)보다 여러 특징에 비중을 분산하고 간격의 극단성보다 균형을 봅니다. [가중 빈도](weighted_frequency.md)는 기간별 빈도 그 자체를 결합하지만 이 공식은 기간 간 차이·굴곡을 주로 사용합니다.

창이 서로 겹치고 파생식도 공통 잔차를 사용하므로 여섯 특징을 여섯 개의 독립적 검증으로 보면 안 됩니다. 현재 구현은 고정 가중치 휴리스틱이며 예측 성능 개선이 입증된 모델이 아닙니다.
