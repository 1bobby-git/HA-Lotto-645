# 공개 공식 · 동반출현쌍

[17개 방식 목록](../../README.md#추천-방식-17종) · [공통 계산 원리](../FORMULAS.md)

`method_id: pair_cooccurrence` · 분류: 공개 분석식 · 후보 풀: **22개**

## 1. 어떤 방식인가요?

두 번호가 **같은 회차의 본번호에 함께 등장한 관계**를 우선합니다. 한 번호가 많이 나왔는지보다 다른 번호들과 어떤 연결을 만들어 왔는지를 보는 방식입니다.

전체 이력과 최근 120회의 관계를 함께 평가하고, 최종 6개 조합 안의 모든 번호쌍도 다시 확인합니다. 단 하나의 유명한 쌍을 무조건 포함하는 규칙은 아닙니다.

## 2. 사용하는 데이터와 계산

지정한 서로 다른 두 번호가 본번호 6개에 함께 포함될 무작위 확률은 `p2=(6/45)×(5/44)=1/66`입니다. 전체·최근 120회에서 각 쌍의 동시출현 횟수를 이 기대값과 비교해 잔차를 계산합니다.

```text
쌍 연결 = 0.68×tanh(z전체쌍/3.0)
          + 0.32×tanh(z최근120쌍/2.2)
```

연결값의 범위는 -1~1입니다. 번호별 그래프 강도는 해당 번호와 다른 44개 번호의 연결 중 음수를 0으로 바꾼 뒤 **가장 강한 6개 평균**입니다. 이 강도를 45개 번호 내부 순위로 변환합니다.

최종 조합 단계에서는 음수를 잘라내지 않고 내부 15개 쌍의 연결을 모두 평균해 `(평균+1)/2`로 변환합니다. 번호 단계의 ‘강한 연결 요약’과 조합 단계의 ‘모든 내부 연결’은 다른 계산입니다.

## 3. 번호 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `graph_strength` | 번호별 상위 양의 연결 강도 | 0.52 |
| `frequency_100` | 최근 100회 출현 강도 | 0.18 |
| `transition` | 다음 회차 전이 | 0.16 |
| `gap_balance` | 간격 균형 | 0.14 |

## 4. 조합 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `individual` | 선택 번호 점수 평균 | 0.66 |
| `pair` | 내부 15개 번호쌍 연결 | 0.30 |
| `balance` | 조합 형태 균형 | 0.06 |

합계 1.02로 정규화합니다. 별도 조합 다양성 가중치는 0이지만, 다른 방식과의 중복 제한은 공통 선택 규칙으로 남아 있습니다.

## 5. 계산 예시

가상 조합의 내부 15개 연결값 평균이 0.30이면 쌍 조합점수는 `(0.30+1)/2=0.65`입니다. 가장 강한 한 쌍이 0.90이어도 나머지 연결이 약하면 평균점수는 그보다 낮습니다.

그래서 센서에 표시되는 `strongest_pair_score=0.90`을 최종 조합 전체의 쌍 점수나 당첨 확률 90%로 해석하면 안 됩니다. 이 수치는 설명용 가상 값입니다.

## 6. 설정과 결과 확인

통합 **구성 → 추천 설정**에서 선택하며 기본 선택에 포함됩니다. 개인정보나 AI는 필요하지 않습니다.

`strongest_pair`와 `strongest_pair_score`는 **최종 선택 조합 내부에서** 가장 강한 쌍을 나타냅니다. `number_feature_scores`의 `graph_strength`, `score_components`의 `pair`, `score_component_weights`를 함께 확인하세요. 전체 45개 번호의 연결 행렬을 센서에 전부 표시하는 기능은 아닙니다.

## 7. 차이와 해석의 한계

[삼중 동반출현](triplet_cooccurrence.md)은 세 번호 묶음을, [전이·간격 위상](transition_gap_phase.md)은 다음 회차의 관계를 더 중시합니다.

쌍 연결은 무작위 기대값에 대한 관찰 잔차이며, 두 번호의 개별 빈도를 조건으로 보정한 인과관계나 상관계수는 아닙니다. 많은 쌍을 살펴보면 우연히 강한 연결이 보일 수 있습니다. 과거 연결이 다음 회차에도 지속된다는 보장은 없습니다.
