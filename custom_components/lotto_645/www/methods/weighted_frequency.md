# 공개 공식 · 가중 빈도

[12개 대표 공식 목록](../../README.md#추첨-공식-12종) · [공통 계산 원리](../FORMULAS.md)

`method_id: weighted_frequency` · 분류: 공개 분석식 · 후보 풀: **22개**

## 통합 옵션

이 대표 공식은 추천 설정에서 아래 계산 중 하나를 선택해 **한 게임**을 생성합니다. 아래 기본 계산 설명은 기본 옵션에만 적용되며 다른 옵션의 정확한 가중치는 각 문서를 확인하세요. 실제 결과의 `generator_settings`에 사용한 설정을 기록합니다.

- [공개 공식 · 핫넘버](hot_numbers.md)
- [공개 공식 · 지수감쇠 최근성](recency_decay.md)

## 1. 어떤 공식인가요?

**최근 10·30·100회와 전체 이력의 출현 정도**를 서로 다른 비중으로 합칩니다. 짧은 기간의 변화에 더 반응하되 장기 이력도 일부 남기는 빈도형 공식입니다.

서로 길이가 다른 기간의 출현 횟수를 그대로 더하지 않습니다. 각 기간의 무작위 기대 횟수 대비 잔차를 구하고, 그 값을 45개 번호 안에서 순위 점수로 바꿔 비교합니다.

## 2. 사용하는 데이터와 계산

각 기간의 실제 회차 수를 `N`, 해당 번호의 본번호 출현 횟수를 `c`, `p=6/45`라 하면:

```text
z기간 = (c - N×p) / sqrt(N×p×(1-p))
기간별 특징 = R(z기간)
```

동일 기간에서는 횟수가 많을수록 높은 순위를 받으며, 같은 횟수는 같은 평균 순위를 받습니다. 이력 길이가 부족하면 존재하는 회차만 사용합니다. 보너스번호는 횟수에 넣지 않습니다.

## 3. 번호 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `frequency_10` | 최근 10회 출현 강도 순위 | 0.34 |
| `frequency_30` | 최근 30회 출현 강도 순위 | 0.28 |
| `frequency_100` | 최근 100회 출현 강도 순위 | 0.23 |
| `frequency_long` | 전체 이력 출현 강도 순위 | 0.15 |

합계는 1.00입니다. 34%는 **번호 점수 구성 비중**이며, 최근 10회의 출현 확률을 34%로 가정하는 뜻이 아닙니다.

## 4. 조합 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `individual` | 선택 6개 번호 점수 평균 | 0.66 |
| `pair` | 조합 내부 번호쌍 연결 | 0.08 |
| `diversity` | 내부 변화 방향·간격 다양성 | 0.06 |
| `balance` | 홀짝·저고·합·범위·구간 균형 | 0.10 |

합계 0.90으로 정규화합니다. 높은 빈도의 번호만 한쪽으로 몰린 조합보다 다른 요소까지 맞는 조합이 선택될 수 있습니다. 공통 유사성 감점과 과거 1등 완전일치 제외도 적용됩니다.

## 5. 계산 예시

특정 번호의 **가상 순위 점수**가 최근 10회 0.9, 30회 0.7, 100회 0.6, 전체 0.4라면:

```text
번호 점수 = 0.34×0.9 + 0.28×0.7 + 0.23×0.6 + 0.15×0.4
          = 0.700
```

최근 10회에서 높게 평가되어도 장기 점수가 낮으면 일부 상쇄됩니다. 원시 출현 횟수나 특정 실제 회차를 사용한 예시는 아니며, 0.700을 70% 당첨 확률로 해석하면 안 됩니다.

## 6. 설정과 결과 확인

통합 **구성 → 추천 설정**에서 선택하며 기본 선택 5개에 포함됩니다. 사주정보나 AI는 필요하지 않습니다. 기간과 가중치는 코드 고정값입니다.

`number_feature_scores`의 네 빈도 특징과 `number_feature_weights`를 비교하세요. `score_components`를 보면 빈도 기반 번호 점수와 번호쌍·균형이 최종 조합에 각각 어떻게 반영되었는지 확인할 수 있습니다. 표시된 특징 점수는 횟수가 아니라 정규화된 값입니다.

## 7. 차이와 해석의 한계

[핫넘버](hot_numbers.md)는 10·30회와 상승 방향에 더 집중하고, [지수감쇠 최근성](recency_decay.md)은 회차마다 연속적으로 다른 가중치를 줍니다. 이 공식은 경계가 명확한 네 관찰창을 사용합니다.

최근 10회는 30·100회·전체에도 포함되므로 서로 독립적인 네 표본이 아닙니다. 많이 나왔다는 관찰은 다음 회차에도 더 잘 나온다는 증거가 아닙니다. `score`와 과거 리뷰 별점은 당첨 확률이 아닙니다.
