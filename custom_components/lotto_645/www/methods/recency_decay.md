# 빈도 프리셋 · 지수감쇠 최근성

[추첨 공식 목록](../../README.md#추첨-공식-19종) · [공통 계산 원리](../FORMULAS.md)

`method_id: recency_decay` · 분류: 공개 분석식 · 후보 풀: **22개**

## 1. 어떤 공식인가요?

가장 최근 회차에 큰 비중을 주고, 과거일수록 영향력을 연속적으로 줄입니다. 고정된 최근 10회 창에서는 경계 밖 회차의 영향이 갑자기 사라지지만, 지수감쇠는 더 매끄럽게 감소합니다.

다만 무한한 과거 전체를 쓰는 것은 아닙니다. 이 구현의 감쇠 빈도 계산은 **최근 최대 260회, 반감기 20회**입니다.

## 2. 사용하는 데이터와 계산

가장 최신 회차의 나이를 `a=0`으로 두고, 한 회차 전은 1로 셉니다.

```text
회차 가중치 w(a) = exp(-ln(2)×a/20) = 2^(-a/20)
가중 출현률(n) = 해당 번호가 나온 회차의 w 합 / 전체 사용 회차의 w 합
감쇠 원시 특징(n) = 가중 출현률(n) - 6/45
```

이 원시 특징을 전체 45개 번호 안에서 상대순위로 바꿉니다. 보너스번호는 포함하지 않습니다. 시간 단위는 날짜가 아니라 회차입니다.

이 공식의 최종 번호 점수에는 감쇠 빈도 외에도 고정 30·100회 빈도, 번호쌍, 간격 균형이 들어갑니다. 따라서 완전히 경계 없는 하나의 지표만 사용하는 공식은 아닙니다.

## 3. 번호 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `frequency_decay` | 반감기 20회 감쇠 빈도 순위 | 0.58 |
| `frequency_30` | 최근 30회 출현 강도 | 0.16 |
| `frequency_100` | 최근 100회 출현 강도 | 0.10 |
| `graph_strength` | 번호쌍 연결 요약 | 0.08 |
| `gap_balance` | 미출현 간격 균형 | 0.08 |

## 4. 조합 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `individual` | 선택 번호 점수 평균 | 0.66 |
| `pair` | 내부 번호쌍 연결 | 0.08 |
| `diversity` | 내부 변화 방향·간격 다양성 | 0.05 |
| `balance` | 조합 형태 균형 | 0.09 |

합계 0.88로 정규화한 뒤 공통 감점과 제외 조건을 적용합니다.

## 5. 계산 예시

다음은 실제 회차 데이터가 아닌 **감쇠식 자체의 값**입니다.

| 최신 회차에서 떨어진 거리 | 해당 회차 가중치 |
|---|---|
| 0회 | 1 |
| 20회 | 0.5 |
| 40회 | 0.25 |
| 60회 | 0.125 |

20회 전 한 번의 출현은 최신 회차 한 번의 출현에 비해 분자 기여가 절반입니다. 그러나 최종 점수는 전체 가중치 합으로 나누고, 45개 번호의 순위까지 적용하므로 단순히 ‘가중치 0.5인 번호’라고 표시하지 않습니다.

## 6. 설정과 결과 확인

통합 **구성 → 추천 설정**에서 선택합니다. 개인 입력이나 AI 연결이 필요하지 않습니다. 반감기 20회와 최대 260회는 코드의 고정값이며 HA 옵션에 반감기 입력란은 없습니다.

`number_feature_scores`의 `frequency_decay`와 30·100회 특징을 비교하면, 연속 감쇠와 고정 창에서 번호의 상대순위가 어떻게 다른지 알 수 있습니다. `score_components`는 그 번호 점수를 포함한 최종 조합 요소를 나타냅니다.

## 7. 차이와 해석의 한계

[가중 빈도](weighted_frequency.md)는 네 창의 상대순위를 합치고, 이 공식은 감쇠 빈도에 가장 큰 비중을 줍니다. [핫넘버](hot_numbers.md)와는 최근 10회 특징과 상승 방향을 직접 넣지 않는 점이 다릅니다.

반감기는 과거 데이터 영향의 감소 속도이지 당첨 가능성이 반으로 줄어드는 기간이 아닙니다. 최근성에 민감하도록 설계한 선택 규칙이며, 무작위 추첨의 예측력이 입증된 것은 아닙니다. `score`와 정규화된 특징 점수는 당첨 확률이 아니며, 0.8을 다음 회차 출현 확률 80%로 해석하면 안 됩니다.
