# 조건 공식 · 조건 지정 균등 생성

[추첨 공식 목록](../../README.md#추첨-공식-24종) · [공통 계산 원리](../FORMULAS.md)

`method_id: constraint_uniform` · 후보 풀: **45개**

## 계산 원리

고정·제외번호, 합계, 홀수, 1~22, 이월수, 이웃수, 소수, 3배수, 같은 끝수, 최대 연속 길이, AC 최솟값을 공통 규칙으로 검사합니다. 이웃수는 직전 본번호 ±1 중 1~45에 있는 수에서 직전 본번호 자체를 뺀 집합입니다. 1은 소수가 아닙니다. 3연속은 최대 길이 3입니다.

고정·제외 후 완성 후보가 20,000개 이하면 모든 조합을 검사해 통과 조합을 reservoir 방식으로 균등 선택합니다. 더 크면 OS CSPRNG 부분 Fisher–Yates로 최대 12,000개 후보를 독립 추출하여 조건을 모두 만족하는 첫 조합을 선택합니다. 성공 조건부로 허용 조합 안에서 균등하며 특정 조건의 당첨 확률 우월성을 의미하지 않습니다.

충돌 입력, 완전 탐색 결과 허용 조합 없음, 탐색 한도 초과를 구분합니다. 조건을 풀거나 다른 공식으로 대체하지 않습니다. 재생성·캐시 복원에도 동일한 조건과 과거 1등 제외를 검사합니다. 설정 변경은 로컬 캐시 키를 바꾸며 기존 다른 공식에는 조건을 강제하지 않습니다.

## 계산 예시

고정번호 `7`, 제외번호 `13`, 홀수 개수 `2-4`를 설정하면 7을 포함하고 13을 제외하며 홀수 개수가 2~4인 조합에서 선택합니다. `7`을 고정·제외에 동시에 넣으면 번호 생성 전에 충돌을 알려줍니다.

## 설정·센서

통합 구성의 **조건 지정 생성 설정**에서 규칙을 저장하고 **추천 설정**에서 이 공식을 선택하세요. `applied_rules`, `constraints_satisfied`, `uniformity`, `restored_from_cache`로 적용 결과를 확인합니다. `eligible_combination_count`는 계산하지 않은 정확한 후보 수를 지어내지 않도록 null입니다. 최초 무제약 설정은 대표 균등 생성과 같은 목적이지만, 규칙을 지정하면 별도 조건 공간을 사용합니다.

## 구현 근거

공개 필터 방식은 입력 조건 인터페이스의 참고이며 독립적으로 구현했습니다. [특허의 공개 필터 설명](https://patents.google.com/patent/KR20180125836A/ko), [공개 Ruleset 구현](https://github.com/woongmur/lottoracle). 특정 사업자의 비공개 알고리즘을 재현했다고 주장하지 않습니다. 실제 구현은 `constraints.py`와 `analysis.py`, 검증은 `tests/test_recommended_formulas.py`를 참고하세요.
