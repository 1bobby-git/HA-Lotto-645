# 공개 공식 · 콜드·미출현

[17개 방식 목록](../../README.md#추천-방식-17종) · [공통 계산 원리](../FORMULAS.md)

`method_id: overdue_gap` · 분류: 공개 분석식 · 후보 풀: **22개**

## 1. 어떤 방식인가요?

현재까지 본번호로 등장하지 않은 간격이 긴 번호를 주로 보되, 너무 긴 간격의 점수는 상한을 둡니다. 장기·최근 빈도가 무작위 기대에서 지나치게 멀어지지 않은지도 보조로 확인합니다.

‘오래 안 나왔으니 나올 차례’라는 확률 법칙을 사용하는 것은 아닙니다. 이 방식은 미출현 간격을 조합 선택의 취향으로 반영하는 휴리스틱입니다.

## 2. 사용하는 데이터와 계산

최신 회차에 나왔으면 현재 간격 `g=0`, 직전 회차가 마지막이면 `g=1`입니다. 한 번도 나오지 않았다면 전달된 전체 이력 길이를 사용합니다.

```text
p = 6/45
기대 미출현 간격 = (1-p)/p = 6.5
간격 표준편차 ≈ 6.9821
gap_z = (g-6.5)/6.9821
상한 간격 = min(max(gap_z,-0.5),2.4)
간격 이례성 = min(abs(gap_z),2.5)
```

이후 두 값을 각각 45개 번호 내 상대순위로 바꿉니다. `gap_surprise`는 절댓값이므로 기대보다 짧은 간격도 포함합니다. 긴 간격을 직접 선호하는 부분은 비중 0.48의 `overdue_capped`입니다.

## 3. 번호 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `overdue_capped` | 상·하한을 둔 미출현 간격 | 0.48 |
| `gap_surprise` | 양방향 간격 이례성 | 0.22 |
| `long_neutral` | 전체 빈도의 중립성 | 0.18 |
| `recent_neutral` | 최근 30회 빈도의 중립성 | 0.12 |

## 4. 조합 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `individual` | 선택 번호 점수 평균 | 0.66 |
| `pair` | 내부 번호쌍 연결 | 0.07 |
| `diversity` | 내부 변화 방향·간격 다양성 | 0.08 |
| `balance` | 조합 형태 균형 | 0.10 |

합계 0.91로 정규화합니다. 긴 간격의 상위 6개를 바로 출력하는 것이 아니라 후보 조합의 연결·형태와 공통 감점까지 평가합니다.

## 5. 계산 예시

**가상 간격** 20회이면 `gap_z≈1.9335`라서 상한 간격 값도 약 1.9335입니다. 40회이면 `gap_z≈4.7980`이지만 상한 간격 값은 2.4, 간격 이례성 값은 2.5로 제한됩니다.

40회와 50회처럼 둘 다 상한을 넘는 번호는 이 특징에서 같은 원점수를 받을 수 있습니다. 따라서 더 오래 안 나왔다는 이유만으로 점수가 계속 커지지 않습니다. 예시는 실제 특정 번호의 현재 미출현 기록이 아닙니다.

## 6. 설정과 결과 확인

통합 **구성 → 추천 설정**에서 선택합니다. 사주정보나 AI는 필요하지 않습니다. 간격 상한을 HA 설정 화면에서 조절하는 옵션은 없습니다.

`gaps_since_last`는 실제로 사용한 선택 번호의 현재 간격이며, `number_feature_scores`는 순위 변환 후 점수입니다. 둘을 같은 숫자로 기대하면 안 됩니다. `score_components`, `number_sum`, `odd_count`도 함께 보면 조합 보정의 이유를 알 수 있습니다.

## 7. 차이와 해석의 한계

[재등장 주기](cycle_rhythm.md)는 번호별 과거 간격 중앙값에 **가까운지**를 보고, 이 방식은 긴 현재 간격에 더 높은 비중을 줍니다. [핫넘버](hot_numbers.md)는 최근 등장 강도에 초점을 둡니다.

상한은 극단적인 점수 쏠림을 줄이는 구현 장치이지 당첨 예측의 정확도를 입증하는 장치가 아닙니다. 공정한 독립 추첨은 앞선 미출현 기록을 보상하지 않습니다. `score`는 당첨 확률이 아닙니다.
