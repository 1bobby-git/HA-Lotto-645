# 2.0.0 배포 전 확인 — 2026-09-16

## 확인 환경

Home Assistant OS / 실제 Core 2026.9.2 / Python 3.14.6 / amd64. 별도 최소 Core API에서 비공개 엔진 1.22.1을 실행했다. 사용자 Windows NUC에서 검사·빌드·GitHub 배포를 수행했으며 유료 Actions는 사용하지 않았다.

## 결과

- 공개 HA 단위 검사 223개 통과. 계산 소스 미포함·QR·저장·리뷰·API 계약·요청 복구 등.
- 실제 Edge 엔진에서 QR PNG 판독, 명시적 저장, 입력 초안 보존, 테마·모바일·태블릿 레이아웃, 23개 공개 안내 문서, 모달 초점·실시간 상태 갱신 검사 통과. 이 브라우저 검사는 합성 HA 응답을 사용한다.
- 실제 설치된 Home Assistant 환경에서 모듈 import, 구성 메뉴의 5개 폼 직렬화, 22개 카탈로그 확인.
- 실제 HACS를 통해 1.20.0에서 후보 버전으로 다운로드, HA 재시작, 기존 통합 ID 유지·로드 성공.
- HA 옵션 흐름으로 HTTPS API와 기기 인증 연결. 인증서 지문을 확인하며 TLS 검증을 끄지 않았다.
- 실제 이번 회차 새 생성 성공. 10개 선택 공식의 결과에 Core 1.22.1과 생성 ID가 기록됨. 별도로 보존된 기존 AI 설명 기록을 새 원격 실적으로 계산하지 않음.
- 반복 조회와 통합 재로딩 후 동일 생성 ID/번호 유지. 단순 조회로 새 번호를 만들지 않음.
- 실제 HA QR 미리보기 → 합성 복권 두 장 등록 → 단일 복권 수정 → 오래된 리비전 저장 거부 → 과거 확정 결과 대조 → 시험 복권만 삭제 완료. 원래 복권 기록은 동일하게 보존.
- 기존 23개 공식 리뷰 행 유지. 이번 주 미발표 추첨 결과는 아직 평가할 수 없음.
- 운영 Core API는 전용 비특권 컨테이너·기기별 토큰·TLS·자원 제한·자동 시작으로 실행. 웹사이트/회원 커뮤니티는 이 릴리스 범위가 아님.

## 변경과 보존

실제 설치 전 기존 컴포넌트와 lotto_645 저장 파일의 비공개 복구용 백업을 HA 공유 디렉터리에 생성했다. 전체 HA 시스템 백업 완료라는 의미는 아니다. 과거 공개 Core 릴리스나 Git 이력을 삭제하지 않았다. 새 HACS 패키지에는 비공개 계산 코드를 넣지 않았다.

## 제한

휴대폰 실물 카메라·모든 제3자 AI 공급자·미래 회차 당첨·장기 부하/장애 전수 검사는 수행하지 않았다. 연결 장애 처리는 자동 검사에서 확인했으며 운영 서비스 강제 중단 시험은 수행하지 않았다. 새 API 연결 없이 일반 1.x 사용자가 바로 업데이트할 수 있는 로컬 생성 버전이 아니다.
