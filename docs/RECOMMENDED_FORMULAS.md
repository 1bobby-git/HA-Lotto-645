# 조건 생성과 합의 사용법

**구성 → 조건 지정 생성 설정**에서 고정·제외·형태 조건을 저장한 뒤 **조건 지정 균등 생성**을 선택합니다. 조건 충돌·불가능한 조건·탐색 한도 초과를 구별하며 조건을 임의로 완화하거나 일반 랜덤 번호로 대체하지 않습니다.

**계열별 다수결**은 실제 생성한 번호마다 표를 부여하되 같은 계열의 중복 표를 보정합니다. **선택 공식 중앙값**의 순번별 중앙값 ±1 규칙과 기존 ID는 변경하지 않습니다. 두 합의는 서로를 입력으로 사용하지 않습니다.

이번 회차 추천은 로또 복권 **한눈에 → 이번 회차 추천번호**에 즉시 반영됩니다. 실제 저장 추천은 결과 발표 후 대조·리뷰합니다. 구매번호 등록 화면에서 저장해야 내 복권으로 보관됩니다.

과거 공식 검증은 Lotto Lab에서만 진행합니다. [동일 코어 실행 계약](CORE_API.md). 제거한 개인 행운 번호·다중 조합·과거 재실행 기능의 코드나 비활성 플래그를 유지하지 않습니다. 업데이트 시 그 기능의 선택 설정과 덮어쓰기 설치가 남긴 파일만 정리하며 실제 추천·구매·리뷰는 삭제하지 않습니다.
