# Home Assistant AI 추천

`method_id: home_assistant_ai` · 분류: Home Assistant AI · 로컬 추천 17종과 별도

## 1. 어떤 방식인가요?

Home Assistant에 설정된 데이터 생성 AI에 번호 추천을 요청하고, 반환된 결과를 이 통합의 검증 규칙으로 확인하는 방식입니다. 고정된 통계 가중치를 사용하는 로컬 방식과 구분됩니다.

## 2. 설정과 실행

로또 통합 구성에서 AI 추천 기능을 설정하고, Home Assistant의 기본 데이터 생성 AI 또는 사용할 `ai_task.*` 엔티티를 선택합니다. AI 추천 생성 버튼 또는 아래 작업으로 요청합니다.

```yaml
action: lotto_645.generate_ai_recommendation
```

설명을 열어 보는 것만으로 AI에 요청하거나 추천번호를 다시 생성하지 않습니다. 서비스 제공자, 응답 시간과 이용 비용은 사용자가 연결한 AI 설정에 따라 다를 수 있습니다.

## 3. 반환된 번호의 검증

반환된 번호의 범위와 중복, 과거 1등 조합과의 완전일치, 로컬 추천의 완전복제를 검증합니다. 검증을 통과했다는 것은 형식과 제외 규칙을 만족한다는 의미이지 예측력이 확인되었다는 의미가 아닙니다.

## 4. 로컬 추천·중앙값 방식과의 차이

AI 추천은 README의 로컬 추천 17종에 포함되지 않습니다. 선택 방식 중앙값 집계에서도 제외됩니다. 일반 `lotto_645.refresh` 작업은 로컬 추천을 재생성하며 기존 AI 추천을 변경하지 않습니다.

## 5. 개인정보와 결과 해석

원본 생년월일·출생시간·출생지는 AI 추천 프롬프트에 넣지 않습니다. 이 설명에는 개인 사주정보, 인증정보 또는 실제 프롬프트를 표시하지 않습니다.

추첨 전에 저장된 AI 추천은 실제 추첨번호와 대조합니다. 추천 이유의 설득력이나 과거 점수·별점이 미래의 당첨 확률을 뜻하지는 않습니다. AI는 당첨을 보장하지 않습니다.
