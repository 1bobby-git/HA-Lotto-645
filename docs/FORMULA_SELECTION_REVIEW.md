# 공개 공식 추가와 기존 공식 정리 검토

> **후속 적용:** 이 문서의 최초 검토 결과는 당시 24종 구성을 설명합니다. 제거·통합 권고는 이후 실제 적용되었습니다. [현재 적용 내역](FORMULA_CONSOLIDATION.md)을 우선 확인하세요. 아래는 변경 전 판단 기록입니다.

검토 기준: 2026-09-14, 기존 main `192273740abe910fc0956f5d976cedf14909089c`의 로컬 공식 23개와 별도 AI 경로. 이번 결과는 **AC 1개 추가, 기존 23개 삭제 없음, 기본 선택 변경 없음**입니다. 예측 우월성을 입증한 백테스트나 성능 순위가 아닙니다.

## 판단 원칙

새로운 이름이나 복잡한 수식보다 사용자가 얻는 **다른 기능**을 기준으로 비교했습니다. 모든 특정 조합의 1등 확률은 공정·독립 추첨 아래 같습니다. 그러므로 예측력이 없다는 이유만으로 모든 공식을 삭제하는 것도, 계산이 가능하다는 이유만으로 모두 추가하는 것도 적절하지 않습니다.

균등 생성, 명확한 형태 제약, 사용자가 요청한 집계·문화적 개인화, 여러 게임의 조건부 커버리지는 서로 다른 목적입니다. 같은 목적과 분포의 구현을 여러 추천 전략으로 세는 것은 구별해야 합니다. 기존 공식의 제거·통합은 **권고만** 하며 저장 ID·엔티티·자동화·사용자 선택을 임의로 삭제하지 않습니다.

## 추가한 공식: AC값 7 이상

`ac_range_filter`는 전체 15개 번호쌍의 서로 다른 양의 차이값 수에서 5를 뺀 값에 하한 7을 적용합니다. 기존 `delta_system`은 첫 번호와 인접 간격 5개를, `balance_formula`는 합계·홀짝·저고·범위·구간 수를 점수화합니다. AC는 기존에 없던 명시적 형태 조건이고, 기존 점수·빈도·상위 후보 풀을 섞지 않은 조건부 균등 샘플러라는 차이가 있습니다.

7은 선택한 제품 기본 기준이며 최적 당첨 임계값으로 검증한 것이 아닙니다. AC 7 이상에 해당하는 전체 조합은 **6,943,080 / 8,145,060 = 약 85.2428%**입니다. 독립 비트셋 구현으로 전체 공간을 열거한 [원시 결과](ac-space-verification.json)이며 과거 적중률이 아닙니다.

[공식 설명](methods/ac_range_filter.md)에는 계산 예시·제외 후 후보 수·성공 조건부 균등성·재시도 상한·캐시 재검증을 기재했습니다. 선택 목록에만 추가하며 자동 활성화하거나 구매 게임 수를 늘리지 않습니다.

## AI에 대한 별도 판단

`ai_formula.py`는 이미 `calibrated_stratified`로 확정한 번호만 설명하도록 프롬프트를 구성합니다. AI가 번호를 반환하거나 다른 공식으로 변경하면 응답 검증에서 거절합니다. 이번에는 신규 AI 공식·프롬프트 변형을 중복 추가하지 않았습니다. 원본 사주정보를 보내지 않는 현재 경계도 유지합니다.

다만 자연어 설명의 모든 허위 주장을 형식 검증만으로 완전히 차단하는 것은 아닙니다. 향후 설명을 고정 사실 템플릿으로 제한하는 개선은 번호 생성과 별도로 검토할 수 있습니다. 이번 변경에서 AI 의미 검증을 완성했다고 주장하지 않습니다.

## 검증과 변경 경계

- AC 정의·전체 공간 수·고정번호·불가능한 조건·재시도 상한·제외 조합·CSPRNG 연결·캐시 복원과 손상 캐시·중앙값 집계를 회귀 테스트 대상으로 추가했습니다.
- UI 도움말·README·공식 목록·실제 공식 개수와 문서 링크를 함께 갱신했습니다. AC 통과 비율은 정확한 전체 공간 계산이며 예측 백테스트가 아닙니다.
- 기존 공식의 선택·ID·기본값·생성 알고리즘을 삭제하거나 통합하지 않았습니다. AC를 선택하기 전에는 추천 개수를 임의로 늘리지 않습니다. 기존 통합·구매번호를 지우거나 사주 프로필을 다시 입력할 필요가 없습니다.
- 브랜치 작업용 소스 내보내기·패치 워크플로는 최종 변경에서 제거하며 제품의 새 정기 작업으로 남기지 않습니다.
