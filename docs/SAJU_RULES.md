# 개인 사주 추천 규칙 감사 · v1.6.0

## 적용 범위

사용자가 제공한 **사주명리 마스터 AI - 완전판 시스템 프롬프트 v2.0**의 명리 계산·분류 규칙을 번호 선택 모듈에 적용했습니다. 원문 전체와 사용자 출생정보는 저장소에 공개하지 않습니다. 연애·건강·투자 상담용 페르소나와 질병 예언, 고정된 오늘 날짜는 로또 엔진의 기능이 아닙니다.

**달력 계산이 맞다는 것, 프롬프트 표를 재현한다는 것, 로또 예측력이 있다는 것은 서로 다른 주장입니다.** 여기서 검증하는 것은 앞의 두 가지 및 코드의 출력 조건입니다. 숫자 가중치와 1~45 반복 배속은 명시적인 현대 응용이며 고전의 표준 공식이나 확률이 아닙니다.

## 교정 또는 분리한 원문 항목

### 1. 일진 기준일 오류

원문 §1.2.11의 `2000-01-01 = 甲辰`은 한국천문연구원 **2000년 월력요항**의 `戊午`와 다릅니다. 구현은 `2000-01-01 = 戊午`를 날짜 차이 계산의 기준으로 사용합니다. 1900/2020/2025/2026년 1월1일도 lunar_python 및 KoreanLunarCalendar의 일진과 교차 시험합니다. 날짜 차이 검산 결과는 각각 甲戌/癸卯/庚午/乙亥입니다. 이 값을 문서가 원래 그렇게 적었다고 주장하지 않습니다.

공식 대조 자료: https://www.kasi.re.kr/publication/post/newsMaterial/2008

### 2. 지지 십신표와 지장간 표의 불일치

예를 들어 원문 지지 십신 조견표에서 갑 일간의 午는 식신이지만, 지장간 표의 午 정기 丁을 천간 십신표로 계산하면 상관입니다. `prompt_branch_ten_god`와 `hidden_main_ten_god`를 별도로 보존합니다. 점수 계산은 명시적인 **지장간 비율 + 천간 100쌍 십신 규칙**을 사용하고 어느 표를 썼는지 표시합니다.

### 3. 亥의 지장간

원문 비율 `戊23%·甲17%·壬60%`를 사용합니다. 일반 라이브러리의 壬/甲 표와 다른 선택이므로 `hidden_stem_rule`에 프롬프트 학파 기준이라고 명시합니다. 통합이 유일한 정통 학파라고 주장하지 않습니다.

### 4. 음력과 시간대

새 프로필의 음력 기준은 한국력이며, 중국력을 명시적으로 선택할 수 있습니다. 기존에 중국 변환으로 저장했던 음력 프로필은 **기존 중국력 선택을 유지**하므로 업데이트가 생일을 조용히 바꾸지 않습니다. 음력 2월30일을 양력 날짜 검증으로 거절하던 문제를 수정했습니다. 모든 변환은 오프라인입니다.

- 한국력: `korean-lunar-calendar==0.4.0`, 날짜/윤달 setter의 성공 여부 확인.
- 중국력과 절기: `lunar_python==1.4.8`.
- 라이브러리의 절기 시각은 UTC+08 기준으로 해석하고 출생 절대시각과 비교합니다. **일주·시주는 출생지의 선택된 시계**로 별도 계산합니다.
- 진태양시는 경도와 균시차 근사식을 적용하는 선택사항입니다. 초 단위 천문 정확도를 주장하지 않으며 적용 분 수를 공개합니다.
- 존재하지 않거나 두 번 존재하는 DST 시각은 거절합니다. 확정된 표준시 시간대/출생기록이 필요합니다.
- 지원 출생연도 1900~2050, 미래 출생일 거절. 출생지를 자동 지오코딩하지 않습니다.

### 5. 시간 미상과 대운

`미상` 또는 `unknown`을 명시하면 **시주를 만들지 않고 3주 분석**합니다. 내부 날짜 변환용 중간 시각은 실제 출생시각으로 표시하지 않습니다. 절입 시점으로 연·월주가 바뀌는 날은 확정 시각이 필요합니다. 출생시간에 따라 반올림 대운 시작 나이가 달라지면 `rounded_age_range`를 표시하고 대운 점수를 제외합니다.

대운은 프롬프트의 **절기까지 일수÷3, 반올림 나이**를 채택합니다. `floor(x+0.5)` 반올림이며, 그 나이의 출생일 시각부터 10년씩 비교합니다. 연도만 같다는 이유로 대운을 조기에 바꾸지 않습니다. 2월29일의 평년 기념일은 2월28일로 정합니다. 분 단위 기산 학파와 혼용하지 않으며 간지 배열·방향·절기 거리·반올림 전후 나이를 공개합니다.

## 점수 체계: 원문 규칙과 구현 가정을 구분

원문에는 아래 수치가 없습니다. **모두 `source_prompt_v2_local_model_v1` 구현 가정**입니다.

### 신강·신약 참고 판정

천간은 각 1단위, 각 지지는 숨은 천간 비율 합계 1단위로 계산합니다. 오행의 원소 개수표와 확장 비율표는 따로 표시합니다.

`월령 지원 40% + 지지 통근 지원 25% + 천간 세력 20% + 오행 질량 지원 15%`

0.40 이하 신약, 0.60 이상 신강, 사이 중화. 월령·통근·투간 증거와 별도로 이 임계값을 노출합니다. 득령/통근을 단일 명리학 표준 계량식으로 확정한 것이 아닙니다.

### 보완오행 후보

억부·조후·통관·병약 근거를 분리합니다. 기본값 0.5에서 억부 +0.24, 여름수/겨울화 +0.16, 상극 양측 각각20% 이상 통관 +0.08, 45% 이상 편중의 설기/제어 +0.06, 최대0.95로 제한합니다. 위 임계값 역시 구현 가정입니다. 특수격과 세부 일간별 조후표가 정의되지 않은 부분을 단정하지 않습니다.

### 번호 점수

| 구성 | 가중치 |
|---|---:|
| 보완오행 후보 적합도 | 0.40 |
| 음양을 구분한 십신 분포 | 0.20 |
| 대운·세운·월운·일운·시운 | 0.24 |
| 합충형파해의 제한된 조정 | 0.12 |
| 음양 참고 균형 | 0.04 |

운 계층 기본 가중치는 0.30/0.25/0.20/0.15/0.10, 없는 계층은 제외 후 재정규화합니다. 각 운의 천간/지지를 둘 다 사용합니다. 합을 무조건 길함이나 합화로 확정하지 않으며 오행 후보와의 적합도에 따라 작은 응용 가중치만 줍니다. 충형파해 조정도 오행별 ±0.08로 제한합니다. 이는 미래 사건 발생 확률이 아닙니다.

조합 점수는 번호 평균45%, 보완오행 비중20%, 오행 종류15%, 음양 균형10%, 과집중 억제10%입니다. 명리 조합 점수와 기존 보조 통계의 최종 결합 가중치는 실제 센서 `score_component_weights`에 표시됩니다.

## 사용자가 확인할 위치

`구성 → 명리 사주정보 입력·수정`에서 저장하고 `추첨 공식·AI·데이터 소스`에서 명리를 선택합니다. 기존 두 메뉴 구조와 엔티티 ID는 유지합니다.

추천 센서 상세 속성에는 `structural_analysis`, `favorable_analysis`, `luck_layers`, `number_ten_god_roles`, `number_score_trace`, `calendar_rules`, `rule_sources`, `calculation_warnings`가 추가됩니다. 사주 프로필 센서에서도 원국/후보/계산법을 확인할 수 있습니다.

원본 생년월일·출생시각·출생지와 전체 프롬프트를 AI 공급자 또는 공유 미러에 전송하지 않습니다. HA 관리자와 HA 백업은 로컬 구성값을 볼 수 있습니다.
