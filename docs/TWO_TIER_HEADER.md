# 2단 모바일/데스크톱 헤더 — v1.11.4

첨부된 Home Assistant 패널 예시처럼 상단을 두 단계로 나눕니다.

1. **Home Assistant 공통 헤더**: 메뉴 버튼 + 컴포넌트 이름 `Lotto 6/45 Analysis`
2. **컴포넌트 헤더**: 로또 원본 로고 + 연결 상태/통합 선택/설정
3. 그 아래에 **한눈에 / 내 복권 / 추천 리뷰** 탭

기존에는 메뉴 버튼과 로고가 같은 행에 있어 Home Assistant의 페이지 제목과 컴포넌트 자체 브랜딩이 구분되지 않았습니다. v1.11.4에서는 메뉴와 컴포넌트 이름을 첫 행으로 분리하고, 로고와 상태 도구를 두 번째 행으로 내립니다.

## 모바일 동작

- iOS의 `--safe-area-inset-top`은 첫 번째 헤더 행 위에 한 번만 적용합니다.
- 컴포넌트 이름은 좁은 화면에서 말줄임 처리하며 메뉴 버튼과 겹치지 않습니다.
- 560px 이하에서 복수 통합 선택기가 표시될 경우 로고 행 아래의 별도 행으로 내려갑니다.
- 기존 상태바/다이내믹 아일랜드, 좌우 노치, 홈 인디케이터 안전 영역 처리는 유지합니다.
- 메뉴 버튼은 44px 원형 조작 영역을 기본으로 사용합니다.

## 유지 범위

원본 로고, 흰색 최근 추첨 결과 카드, 번호 공 색상, 구매번호/추천 리뷰/QR/저장/AI/추천 알고리즘/센서 ID는 변경하지 않습니다. `lotto-panel.js`는 작은 진입 모듈이 되고 기존 컨트롤러는 `lotto-panel-core.js`로 그대로 보존합니다. 이 분리는 레이아웃 오버레이만 추가하기 위한 것이며 데이터 처리 로직은 변경하지 않습니다.

## 검증

브라우저 smoke는 실제 진입 모듈과 core 모듈을 모두 로드하고 `Lotto 6/45 Analysis` 제목이 렌더링되는지 확인합니다. 안전 영역 검사는 첫 행의 메뉴·제목 정렬, 두 번째 행의 로고·설정 위치, 탭 순서, 복수 통합 선택 행, dialog 및 하단 알림을 320~1440px와 여러 inset 조합에서 검사합니다.
