# 공개 공식 · 재등장 주기

> v1.15.0부터 새 생성에서 제외된 공식입니다. 이전 결과의 설명을 위해 이 문서를 보존합니다.

[추첨 공식 목록](../../README.md#추첨-공식-22종) · [공통 계산 원리](../FORMULAS.md)

`method_id: cycle_rhythm` · 분류: 공개 분석식 · 후보 풀: **22개**

## 1. 어떤 공식인가요?

각 번호가 과거에 다시 등장하기까지 걸린 **회차 간격의 중앙값**과 현재 위치를 비교합니다. 오래 안 나온 정도 자체보다, 해당 번호에서 관찰한 대표 간격에 가까운지를 봅니다.

‘주기’는 반복을 설명하는 휴리스틱 명칭입니다. 로또가 기억을 가지거나 일정 간격마다 번호를 보상한다는 뜻이 아닙니다.

## 2. 사용하는 데이터와 계산

번호가 등장한 이력 위치를 모으고 이웃한 위치의 차이를 구합니다. 그 간격들의 중앙값을 `T`, 최신 회차 기준 미출현 간격을 `g`라고 하면:

```text
다음 회차에서의 재등장 간격 = g+1
주기 원점수 = -abs((g+1)-T) / max(T,1)
```

0에 가까울수록 대표 간격과 가깝고, 음의 방향으로 멀어질수록 낮게 평가합니다. 이 값을 45개 번호 내부 순위로 바꿉니다.

과거 등장 횟수가 2회 미만이면 간격을 관찰할 수 없으므로 **최종 주기 특징을 0.5로 둡니다.** 없는 주기를 7회 등으로 만들어 넣지 않습니다. 이 중립값 처리가 그 번호의 다른 모든 특징까지 중립으로 바꾼다는 뜻은 아닙니다.

## 3. 번호 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `cycle_fit` | 번호별 대표 재등장 간격과의 근접성 | 0.46 |
| `gap_balance` | 이론 기대 미출현 간격과의 근접성 | 0.18 |
| `frequency_100` | 최근 100회 출현 강도 | 0.14 |
| `transition` | 다음 회차 전이 | 0.12 |
| `long_neutral` | 장기 빈도 중립성 | 0.10 |

`cycle_fit`의 기준은 번호별 관찰 중앙값이고, `gap_balance`의 기준은 모든 번호에 같은 이론 기대값입니다.

## 4. 조합 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `individual` | 선택 번호 점수 평균 | 0.66 |
| `pair` | 내부 번호쌍 연결 | 0.08 |
| `diversity` | 내부 변화 방향·간격 다양성 | 0.08 |
| `balance` | 조합 형태 균형 | 0.10 |

합계 0.92로 정규화하고 공통 감점과 제외 조건을 적용합니다.

## 5. 계산 예시

한 번호의 **가상 등장 위치**가 `[1,8,14,23]`이면 관찰 간격은 `[7,6,9]`, 중앙값 `T=7`입니다.

현재 `g=6`이면 다음 회차 간격은 7이므로 원점수는 0입니다. `g=14`이면 다음 회차 간격은 15라서 원점수는 `-8/7≈-1.1429`가 됩니다. 따라서 더 오래 안 나온 두 번째 경우가 주기 근접성에서는 오히려 낮습니다.

이는 실제 번호의 주기를 찾아낸 결과가 아닌 계산 예시입니다. 최종 특징은 상대순위이므로 원점수 0을 ‘점수가 없다’고 읽으면 안 됩니다.

## 6. 설정과 결과 확인

통합 **구성 → 추천 설정**에서 선택합니다. 개인 입력이나 AI는 필요하지 않습니다.

`gaps_since_last`, `number_feature_scores`의 `cycle_fit`·`gap_balance`, `score_components`를 함께 확인하세요. 번호별 과거 간격 전체 목록이나 중앙값이 일반 센서 속성에 모두 노출되는 것은 아닙니다. 자세한 재현은 `_cycle_fit`에 동일 이력을 입력하는 코드 수준 검증이 필요합니다.

## 7. 차이와 해석의 한계

[콜드·미출현](overdue_gap.md)은 현재 간격이 긴 쪽에 더 높은 비중을 주지만, 재등장 주기는 관찰 대표값에서 양쪽으로 멀어지는 것을 낮게 평가합니다.

중앙값은 큰 이상치의 영향을 줄이지만 무작위 간격에서 실제 반복 법칙을 만들어 주지 않습니다. 이력 길이가 짧거나 관찰 간격이 불규칙하면 해석에 특히 주의해야 합니다. `score`는 다음 회차 출현 확률이 아닙니다.
