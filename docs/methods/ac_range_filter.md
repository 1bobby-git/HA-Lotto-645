# 형태 공식 · AC값 7 이상

[12개 대표 공식 목록](../../README.md#추첨-공식-12종) · [공통 계산 원리](../FORMULAS.md)

`method_id: ac_range_filter` · 분류: 조합 형태 필터 · 후보 풀: **45개**

## 1. 어떤 공식인가요?

모든 번호쌍의 **서로 다른 양의 차이값**이 충분히 다양한 조합을 선택합니다. 기존 델타 시스템은 첫 번호와 인접 간격 5개를 평가하지만, AC는 6개 번호로 만드는 **15개 쌍 전체**를 평가합니다. 두 공식은 계산 대상과 선택 과정이 다릅니다.

빈도·미출현·홀짝·합계 점수를 더하지 않습니다. AC 7 이상은 명시적인 형태 선택 기준이며, 연구로 최적화된 당첨 임계값이 아닙니다. 값이 높다고 무조건 더 좋은 번호가 아닙니다.

## 2. 계산 원리

```text
D = { x[j] - x[i] | 1 <= i < j <= 6, x는 오름차순 }
AC = 서로 다른 D의 원소 수 - 5
허용 조건: AC >= 7
```

AC 범위는 0~10입니다. `15 - 5 = 10`이 상한입니다. 범위를 벗어나는 번호, 중복, 불리언·실수 또는 번호 개수 오류를 거절합니다.

운영 환경의 난수원은 OS 기반 `secrets.SystemRandom`입니다. 부분 Fisher–Yates로 생성한 후보가 AC 조건과 기존 제외 조건을 모두 만족할 때 채택합니다. 따라서 **성공한 결과는 허용 공간 안에서 조건부 균등**하며 전체 8,145,060개 조합에서 균등한 것은 아닙니다. AC 7·8·9·10 자체를 각각 같은 확률로 선택하는 것도 아닙니다.

## 3. 계산 예시

`2, 5, 11, 17, 21, 33`의 서로 다른 차이값은
`3, 4, 6, 9, 10, 12, 15, 16, 19, 22, 28, 31`의 12개입니다.

```text
AC = 12 - 5 = 7  → 통과
1, 2, 3, 4, 5, 6 → 차이값 1,2,3,4,5 → AC = 0 → 거절
```

예시는 계산 설명용이며 추천 또는 실제 회차 예측이 아닙니다.

## 4. 후보 수·확률 해석

전체 8,145,060개 조합 중 AC 7 이상은 **6,943,080개**, 약 **85.2428%**입니다. 이는 전체 조합의 형태 분포이지 과거 적중률이나 한 게임의 당첨확률이 아닙니다. 해당되지 않는 조합도 정상적인 당첨 후보입니다.

과거 1등 조합, 같은 배치의 동일 조합, 재생성 시 전달받은 기존 조합 제외를 유지합니다. `eligible_combination_count`에는 **AC 조건을 만족하는 제외 조합만** 중복 없이 차감합니다. AC 0인 과거 조합은 AC 공간에 원래 없으므로 또 빼지 않습니다.

공정·독립 추첨에서 개별 한 게임의 1등 확률은 여전히 **1/8,145,060**입니다. 생성 공간 축소가 예측력 향상은 아닙니다.

## 5. 고정번호·재시도·저장

엔진 API는 기존 고정번호를 지원하지만 이번 변경으로 일반 옵션 화면에 고정번호 입력을 추가하지는 않습니다. 완성 후보가 20,000개 이하인 경우 전부 확인하고 허용 후보에서 균등 선택합니다. 허용 후보가 없으면 명시적으로 오류를 반환합니다.

더 큰 공간에서는 최대 512번 균등 후보를 생성합니다. 상한 도달 시 오류로 끝내며 **AC 기준·고정번호·제외 조건을 임의로 완화하지 않습니다.** 재시도 상한은 해가 없다는 증명이 아닙니다. 사전순 채우기나 조건 없는 균등 공식으로 바꿔 성공한 것처럼 처리하지 않습니다.

재시작 시 기존 캐시 정책으로 같은 번호를 복원하며 AC 조건도 재검사합니다. AC에 맞지 않는 손상 캐시는 거절합니다. AC 자체의 조건은 유지합니다. 기존 공식의 선택과 기본값은 대표 12개 구성으로 자동 통합됩니다. AC는 자동 활성화하지 않으며, 선택한 실제 AC 추천번호는 다른 로컬 공식과 함께 중앙값 집계에 참여할 수 있습니다. 중앙값 결과까지 AC 7 이상을 강제하지는 않습니다.

## 6. 설정과 실제 계산 확인

**설정 → 기기 및 서비스 → Lotto 6/45 Analysis → 구성 → 추천 설정**에서 **형태 공식 · AC값 7 이상**을 추가 선택합니다.

결과의 `ac_value`, `ac_minimum`, `distinct_pair_difference_count`, `shape_base_combination_count`, `shape_base_acceptance_ratio`, `eligible_combination_count`를 확인하세요. 근거 문장에도 실제 AC 계산값을 표시합니다. `score`는 `null`이고 `history_used_for_weighting`은 `false`입니다. AI 호출이나 별도 외부 데이터 수집은 하지 않습니다.
