# 분할 위험 참고 · 비인기 패턴 회피

`method_id: crowd_pattern_avoidance` · 후보 풀: **45개**

## 계산 원리
생일 범위(1~31) 집중, 긴 연속수, 일정한 간격, 끝자리 집중, 마킹 용지 모양 등을 구매 선호의 대리지표로 사용합니다. 최대 256개 후보에서 대리 감점이 낮은 조합을 선택하며 동점은 난수로 결정합니다. 과거 1등 완전일치와 같은 실행의 기존 조합은 제외합니다.

## 계산 예시
1·2·3·4·5·6은 생일 범위에 집중되고 연속된 모양이므로 높은 감점을 받습니다. 7·16·25·34·39·45처럼 비교적 분산된 모양을 선호할 수 있으나, 이것이 미래 당첨 확률 또는 실제 구매 인기도를 뜻하지는 않습니다.

실제 한국 조합별 구매 데이터를 학습한 모형이 아닙니다. 공동당첨 감소나 기대상금 증가가 검증된 공식으로 표시하지 않습니다. 감점은 확률이 아닙니다.
