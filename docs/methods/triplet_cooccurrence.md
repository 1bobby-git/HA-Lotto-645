# 공개 공식 · 삼중 동반출현

[23개 공식 목록](../../README.md#추첨-공식-23종) · [공통 계산 원리](../FORMULAS.md)

`method_id: triplet_cooccurrence` · 분류: 공개 분석식 · 후보 풀: **23개**

## 1. 어떤 공식인가요?

세 번호가 같은 회차에 함께 등장한 이력을 평가합니다. 두 번호 관계만으로는 구분하기 어려운 **세 번호 묶음의 동시출현 형태**를 조합 선택에 반영합니다.

세 번호가 자주 함께 나왔다는 사실이 더 강한 예측 증거라는 뜻은 아닙니다. 쌍보다 드물게 관찰되므로 표본 부족과 우연한 편차에 특히 주의해야 합니다.

## 2. 사용하는 데이터와 계산

지정한 세 번호의 무작위 동시포함 확률은 `p3=(6/45)×(5/44)×(4/43)`입니다. 전체 및 최근 180회 이력에서 동시출현 횟수와 기대 횟수의 표준화 잔차를 구합니다.

```text
삼중 연결 = 0.72×tanh(z전체삼중/3.2)
            + 0.28×tanh(z최근180삼중/2.4)
```

번호별 삼중 강도는 해당 번호가 포함된 삼중 연결의 음수를 0으로 바꾸고 **상위 10개 평균**을 계산한 뒤 순위화합니다. 최종 6개 조합은 내부에 20개 삼중 묶음이 있으므로, 조합 단계에서는 그 20개 연결의 평균을 `(평균+1)/2`로 바꿉니다. 이때 음의 연결도 평균에 포함합니다.

번호쌍 보조 특징은 별도의 전체·최근 120회 계산을 사용합니다. 삼중의 최근 180회와 혼동하지 마세요.

## 3. 번호 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `triplet_strength` | 번호별 상위 삼중 연결 요약 | 0.46 |
| `graph_strength` | 번호쌍 연결 요약 | 0.20 |
| `frequency_100` | 최근 100회 출현 강도 | 0.14 |
| `gap_balance` | 간격 균형 | 0.10 |
| `long_neutral` | 장기 빈도 중립성 | 0.10 |

## 4. 조합 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `individual` | 선택 번호 점수 평균 | 0.66 |
| `pair` | 내부 15개 번호쌍 연결 | 0.08 |
| `triplet` | 내부 20개 삼중 연결 | 0.28 |
| `balance` | 조합 형태 균형 | 0.06 |

합계 1.08로 정규화한 뒤 공통 감점을 적용합니다. ‘상위 삼중 묶음 2개를 이어 붙이면 끝’인 구조가 아니라 23개 후보에서 6개 조합을 평가합니다.

## 5. 계산 예시

가상 조합 내부의 삼중 연결 20개 평균이 0.20이면 `triplet` 조합점수는 0.60입니다. 이 구성요소의 정규화 가중치는 `0.28/1.08≈0.2593`이므로 감점 전 합산 기여는 약 `0.1556`입니다.

0.60이나 0.1556은 적합도 구성값입니다. 특정 묶음의 미래 출현 확률이 아니며, 예시는 실제 회차 기록으로 계산한 결과가 아닙니다.

## 6. 설정과 결과 확인

통합 **구성 → 추천 설정**에서 선택합니다. 사주정보와 AI는 필요하지 않습니다. 후보 풀 23개와 기간·가중치는 코드에 고정되어 있습니다.

`number_feature_scores`의 `triplet_strength`, `graph_strength`와 `score_components`의 `triplet`, `pair`를 비교하세요. 공통 설명에 등장하는 `strongest_pair`는 여전히 두 번호짜리 연결입니다. 이 값 하나가 삼중 공식의 전체 근거를 대표하지는 않습니다.

## 7. 차이와 해석의 한계

[동반출현쌍](pair_cooccurrence.md)보다 한 번호를 더 묶어서 관찰하고, 최종 조합에서 삼중 연결에 높은 추가 비중을 줍니다. 후보 풀이 기본 22개보다 1개 크므로 탐색 조합 수도 늘어납니다. 이는 성능·정확도 향상의 보장은 아닙니다.

`tanh`와 보조 지표는 극단적인 점수 영향을 줄이는 장치일 뿐 희소 표본의 통계적 불확실성을 없애지 않습니다. 많은 삼중 묶음 중 높게 나온 과거 관찰값을 미래 당첨 확률로 해석하면 안 됩니다.
