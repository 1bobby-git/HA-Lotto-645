# 실험 공식 · 베이지안 수축

[12개 대표 공식 목록](../../README.md#추첨-공식-12종) · [공통 계산 원리](../FORMULAS.md)

`method_id: bayesian_shrinkage` · 분류: 실험적 개인화 · 후보 풀: **45개**

## 1. 어떤 공식인가요?

기존 저장 ID를 유지하면서 강한 점수 순위 선정을 **약한 빈도 가중 비복원추출**로 교체했습니다. 최근 최대 300회의 편차를 사전 강도 500으로 수축하고, 그 결과를 균등 분포에 5%만 섞습니다. 과거 편차가 다음 당첨을 예측한다는 근거는 없습니다.

## 2. 실제 계산

```text
W = min(300, 과거 회차 수), κ = 500, λ = 0.05
posterior_i = (f_i + κ×6/45)/(W+κ)
w_i = (1-λ)/45 + λ×posterior_i/6
정수 가중치 = 114×(W+500) + 45×f_i + 3000
```

정수 가중치로 한 번호씩 뽑고 선택한 번호는 제거합니다. 이 가중치는 **순차 추출 가중치**이지 최종 티켓의 번호 포함 확률이 아닙니다. 순위 재정규화·최고점 후보 탐색·쌍 점수·균형 감점을 적용하지 않습니다. 혼합률을 받는 내부 계산 함수는 0~10%만 허용하며 현재 UI에서는 5%로 고정합니다.

## 3. 계산 예시

가상으로 최근 300회에서 한 번호가 60번 나왔다면 사후 평균은 `(60+500×6/45)/800 = 0.1583333333`입니다. 혼합 가중치는 `0.95/45+0.05×0.1583333333/6 = 0.0224305556`으로, 균등 가중치 `0.0222222222`에 가깝습니다. 20%라는 관측률을 당첨 예측 확률이나 20% 선택 가중치로 그대로 확대하지 않습니다.

## 4. 결과와 검증

`history_lookback=300`, `prior_strength=500`, `history_mix=0.05`, `history_cutoff_round`, `uniformity=nonuniform_experimental`, `formula_version=2`를 표시합니다. 점수형 후보가 아니므로 `score=null`입니다. 저장된 번호를 재시작 후 복원하며 중복·과거 1등 제외를 적용합니다. 제외가 너무 강하면 균등 추출로 몰래 바꾸지 않고 오류를 반환합니다.

이 공식은 **비균등한 실험적 개인화**입니다. 정확한 균등 추첨이 필요하면 Fisher–Yates 또는 CCSS를 사용합니다. 어느 공식도 한 게임의 실제 1등 확률 `1/8,145,060`을 높이지 않습니다. 별도 미래 구간 예측력 우위는 입증하지 않았습니다.

종합 앙상블에 남아 있는 호환 키 `bayesian_60`는 현재 최대 300회·사전 강도 500의 편차를 특징으로 읽습니다. 그 점수형 경로는 이 가중 샘플링 공식과 별개입니다.

기존 베이지안+점수형 공식+중앙값 설정 호환을 위해 중앙값 집계에는 `0.5+0.05×(bayesian_feature-0.5)`라는 약한 선호 점수를 제공합니다. 이는 번호 추출 가중치나 당첨확률이 아니며, 실제 베이지안 티켓은 별도의 정수 가중 샘플러가 생성합니다.
