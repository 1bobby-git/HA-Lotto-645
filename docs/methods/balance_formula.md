# 공개 공식 · 균형 필터

[23개 공식 목록](../../README.md#추첨-공식-23종) · [공통 계산 원리](../FORMULAS.md)

`method_id: balance_formula` · 분류: 공개 분석식 · 후보 풀: **24개**

## 1. 어떤 공식인가요?

홀짝, 낮은 번호와 높은 번호, 합계, 전체 범위와 번호 구간을 사용해 **6개 조합의 모양**을 평가합니다. 이름은 필터지만 모든 목표를 만족해야 통과하는 강제 조건은 아닙니다. 목표에서 멀어질수록 해당 점수가 줄어드는 소프트 점수입니다.

번호합 기대값 138은 `6×23`에서 오지만, 홀수 3개·저구간 3개·범위 34 등의 목표와 가중치는 고정 휴리스틱입니다. 실제 이력으로 학습한 최적 조합 형태가 아닙니다.

## 2. 사용하는 데이터와 계산

오름차순 조합에서 홀수 개수 `O`, 1~22 개수 `L`, 번호합 `S`, 최고-최저 차이 `W`, 포함된 번호 구간 수 `B`를 계산합니다. 높은 구간은 23~45입니다.

```text
홀짝 점수 = max(0,1-abs(O-3)/3)
저고 점수 = max(0,1-abs(L-3)/3)
합 점수   = max(0,1-abs(S-138)/72)
범위 점수 = max(0,1-abs(W-34)/28)
구간 점수 = min(B/5,1)
균형 점수 = 0.23×홀짝 + 0.23×저고 + 0.24×합
            + 0.15×범위 + 0.15×구간
```

실제 번호 구간은 **1~10 / 11~20 / 21~30 / 31~40 / 41~45**입니다. 1~9 / 10~19로 나누는 공식이 아닙니다.

## 3. 번호 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `long_neutral` | 장기 빈도 중립성 | 0.32 |
| `recent_neutral` | 최근 30회 빈도 중립성 | 0.28 |
| `gap_balance` | 간격 균형 | 0.22 |
| `frequency_100` | 최근 100회 출현 강도 | 0.18 |

조합 모양을 중시하지만 번호 단계에서도 후보를 정렬합니다. 45개 모든 조합의 균형만 계산하는 공식은 아닙니다.

## 4. 조합 단계 가중치

| 내부 키 | 의미 | 원시 가중치 |
|---|---|---|
| `individual` | 선택 번호 점수 평균 | 0.66 |
| `pair` | 내부 번호쌍 연결 | 0.05 |
| `diversity` | 내부 변화 방향·간격 다양성 | 0.10 |
| `balance` | 위의 균형 계산값 | 0.36 |

합계 1.17로 정규화합니다. `balance`의 실제 비중은 약 30.77%이며 나머지 요소와 공통 감점도 최종 결과에 반영됩니다.

## 5. 계산 예시

설명을 위한 가상 조합 `[3,11,20,28,35,41]`은 홀수 4개, 저구간 3개, 합 138, 범위 38, 포함 구간 5개입니다. 위 식을 적용한 **균형 요소 점수**는 약 `0.901905`입니다.

홀짝이 3:3이 아니어도 유효한 후보입니다. 0.901905는 최종 `score`가 아니고 당첨 확률도 아닙니다. 이 번호를 실제 추천 또는 특정 회차 분석 결과로 제시한 것이 아닙니다.

## 6. 설정과 결과 확인

통합 **구성 → 추천 설정**에서 선택합니다. 목표 합계·홀짝 비율을 별도로 입력하는 UI는 없습니다.

`number_sum`, `odd_count`, `low_count_1_22`, `score_components`의 `balance`를 확인하세요. 전체 점수가 높은 이유를 파악할 때 `number_feature_scores`와 `historical_similarity_penalty`도 함께 봅니다. 합계가 정확히 138이 아니어도 오류가 아닙니다.

## 7. 차이와 해석의 한계

[델타 시스템](delta_system.md)은 인접 간격의 크기와 반복에 집중합니다. 이 공식은 전체 합계·홀짝·저고·번호대에 더 많은 비중을 줍니다.

어떤 형태의 조합이 많은 경우의 수를 차지하는 것과, 그중 특정 한 조합의 확률이 높은 것은 다릅니다. 균형이 좋은 한 조합이 불균형한 다른 한 조합보다 당첨 확률이 높아지는 것은 아닙니다.
