# 추첨 공식 설명 · 단일 스크롤 · 추첨 카운트다운

## 추첨 공식 상세 안내

추천 리뷰의 **이번 추첨, 추천번호 결과**와 **공식별 누적 리뷰**에서 파란 점선 밑줄이 있는 공식 이름을 누른다. 상세 설명 팝업에서 사용하는 데이터, 계산 원리, 가중치, 가상 예시, 설정과 해석의 한계를 확인할 수 있다. Escape 또는 닫기 버튼으로 닫으면 누르던 공식으로 초점이 돌아간다.

기존 `docs/methods/` 23개 문서의 원본 바이트를 `custom_components/lotto_645/www/methods/`에 함께 배포한다. HACS가 통합 폴더만 설치해도 설명이 동작한다. AI 설명은 [별도 문서](AI_RECOMMENDATION.md)이며 로컬 23종에 합산하지 않는다. 안내를 열어도 추천을 재생성하거나 AI에 요청하지 않는다.

문서는 처음 여는 공식만 **사용자 HA의 로컬 정적 경로**에서 읽고 이후에는 메모리 캐시를 이용한다. 이미지 업로드, 외부 글꼴/파서/CDN 요청은 없다. 원문 링크를 사용자가 클릭하면 해당 문서가 새 탭으로 열린다. Markdown의 HTML은 실행하지 않고 문자로 표시하며 실행 가능한 URL은 링크로 만들지 않는다. 문서 로딩에 실패하면 재시도와 원문 링크를 제공한다.

## 스크롤

로또 custom element는 HA가 할당한 본문 영역의 정상 흐름 안에서 동작한다. 페이지의 세로 스크롤 소유자는 로또 패널 하나이며 표는 높이 제한 없이 흐른다. 좁은 표에서 번호는 필요한 경우 줄바꿈한다.

설명 팝업과 복권 등록창은 본문만 스크롤하고 배경 패널은 잠근다. HA 자체 사이드바의 독립 스크롤은 정상이며 제거하지 않는다. 부모 HA DOM/Shadow DOM이나 전역 document 스크롤 스타일을 수정하지 않는다.

## 회차별 추첨 카운트다운

동행복권 [로또6/45 소개](https://www.dhlottery.co.kr/lt645/intro)는 인터넷 판매시간을 **일~금 06:00~24:00, 토요일 06:00~20:00**, 정규 추첨시간을 **매주 토요일 20:35경**으로 안내한다(2026-09-14 확인). 판매점 운영시간과 실제 방송 편성은 달라질 수 있다.

카운트다운은 별도 카드로 만들지 않고 **한눈에 화면의 `이번 주의 작은 기대.` 소개 영역**에 표시한다. HA 서버의 한국시간과 정규 주간 회차를 기준으로 일·시간·분·초를 계산하며 브라우저는 숫자만 갱신한다. 매초 서버나 동행복권 사이트를 조회하지 않고, 화면 비활성화·페이지 이탈 시 타이머를 중단한다.

동작 규칙은 다음과 같다.

- 토요일 20:35 전: 해당 회차 추첨까지 남은 시간을 표시한다.
- 토요일 20:35부터: **`0일 00시간 00분 00초`로 고정**한다. 결과 수신 여부 때문에 다음 회차로 미리 넘어가지 않는다.
- 일요일 06:00: 동행복권 인터넷 판매시간상 다음 회차 구매가 다시 가능한 시점으로 보고, **그 순간 다음 토요일 20:35를 향한 새 카운트다운을 시작**한다.
- 앱 복귀: 현재 서버 기준 시각에서 즉시 다시 계산한다. 기존 상태 동기화 정책과 추첨 결과 수신은 별도 동작이다.

카운트다운은 정규 일정 안내일 뿐 실제 방송 시작, 결과 확정 또는 오프라인 판매점 영업 여부를 판정하지 않는다. 기존 추천/AI/센서 ID/저장/revision/결과 대조를 변경하지 않는다.

## 번호 공 색상

페이지에 표시하는 **최근 추첨번호, 보관한 복권, 추천번호**의 모든 번호 공은 동일한 5구간 색상을 사용한다. v1.11.11에서는 사용자가 제공한 동행복권 결과 화면의 실제 픽셀을 기준으로 더 진한 색으로 조정했다.

- 1~10: `#E08F00`
- 11~20: `#0063CC`
- 21~30: `#D8314F`
- 31~40: `#6D7381` — 두 번째 제공 화면의 30번대 공 기준
- 41~45: `#2C9E44`

숫자는 흰색으로 유지하고, 기존 번호 공의 크기·간격·반응형 배치는 변경하지 않는다. 강제 색상 접근성 모드에서는 시스템 색상과 테두리를 사용한다.

## 검증 범위

`tests/test_panel_metadata.py`는 KST/UTC, 토요일 추첨시간 이후 0 유지, 일요일 06:00 판매 재개 경계, 23개 문서 원본과 번들 일치, AI 문서 분리를 검사한다.

`tests/test_draw_ball_styles.py`와 `scripts/smoke_panel_design_system.py`는 다섯 색상과 최근 추첨·내 복권·추천 리뷰의 번호 공에 동일 팔레트가 적용되는지 실제 계산 스타일로 확인한다.

`scripts/smoke_ticket_panel.py`는 기존 QR·저장·초안·디자인·safe-area·HA 사이드바 레이아웃 검사를 유지하고 `smoke_panel_tools.py`를 실행한다. 실제 배포 모듈에서 24개 설명, 양쪽 표의 클릭, 로딩 오류/재시도/캐시, 초점 순환·복귀, Markdown 안전 처리, 단일 스크롤, 팝업 safe-area, hero 카운트다운의 0 유지와 일요일 06:00 재시작, 타이머의 WebSocket 요청 없음과 해제를 검증한다.

브라우저 테스트의 HA 응답과 할당 viewport는 fixture다. 실제 사용자 HA와 물리 iPhone/Safari 검증은 별도다.
