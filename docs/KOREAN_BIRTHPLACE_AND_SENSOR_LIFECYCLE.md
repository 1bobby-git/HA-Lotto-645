# 한국 출생지 선택과 선택형 센서 수명주기

## 명리 사주 출생지

새 설정에서는 출생지를 자유 문자열로 입력하지 않고 대한민국 17개 시·도에서 선택합니다. 한국 출생지는 `Asia/Seoul` 시간대를 자동 적용하며 외부 지오코딩 API나 지역 데이터 다운로드를 사용하지 않습니다.

기존 버전에서 해외 출생지와 다른 시간대를 이미 저장한 사용자는 해당 **기존 값 한 개만** 호환 선택지로 유지할 수 있습니다. 새 임의 해외 문자열은 추가할 수 없습니다. 진태양시 보정을 켠 경우 경도 입력은 기존 정책대로 사용자가 별도로 입력합니다.

## 추첨 공식 센서

추첨 공식 설정을 저장하면 통합이 재로드됩니다. 재로드 시 현재 선택된 공식별 추천 센서만 다시 생성하며, 이 통합의 엔티티 레지스트리에서 선택 해제된 공식별 센서를 삭제합니다.

같은 규칙으로 AI 추천을 끄면 AI 추천 센서를, 명리 공식을 선택 해제하면 명리 사주 프로필 센서를 삭제합니다. 추천 요약, 공식 안내, 추첨 결과, 구매번호 같은 고정 센서는 삭제하지 않습니다.

엔티티 삭제는 Home Assistant 엔티티 레지스트리의 표시 항목을 정리하는 작업입니다. 과거 추천 리뷰, 과거 검증 집계, 구매번호 저장소 및 기타 영속 데이터는 삭제하지 않습니다. 나중에 같은 공식을 다시 선택하면 같은 고유 ID를 사용하는 새 센서가 정상적으로 등록됩니다.
