# 연구 공식과 조합 설계 추가

## 사용 방법

통합 설정 → 기본 추첨 공식에서 다음 두 공식을 추가 선택합니다. 기존 선택과 기본 균등 공식은 자동 변경하지 않습니다.

| 기능 | 구현 목적 | 한계 |
|---|---|---|
| 비인기 패턴 회피 | 생일 범위, 긴 연속수, 6수 등차수열, 같은 끝자리 집중에 대한 대리지표를 피함 | 구매 데이터가 없는 휴리스틱. 최대엔트로피를 학습한 결과, 인기 확률, 기대수익 개선율이 아님 |
| 3수 커버리지 보완 | 다른 로컬 추천 생성 후 새로운 3수 부분집합을 많이 포함하는 조합 선택 | 전체 6수 추첨 결과의 당첨 범위를 직접 최적화하는 것이 아닌 대리지표. 전역 최적성 미증명 |

두 방식 모두 정수 OS 난수로 최대 256개 허용 후보를 생성하고 목적 지표가 가장 좋은 후보의 동점을 무작위로 처리합니다. 작은 고정번호 공간은 전수 검사합니다. 새 외부 라이브러리나 AI 호출이 없습니다.

3수 커버리지는 일반 로컬 공식 이후, 합의 추천 이전에 생성합니다. 참조 추천이 없으면 기존 Fisher–Yates 균등 추출을 사용하고 그 사실을 표시합니다. 기존 추천을 수정하지 않고 보완 조합 1게임을 생성합니다. 선택 순서는 설정에 보존되고 실제 실행 순서는 메타데이터에 남습니다.

과거 1등 조합 제외, 동일 조합 중복 방지, 고정번호, 저장번호 복원, 합의 추천을 유지합니다. 복원된 커버리지 번호는 재최적화했다고 표시하지 않습니다. 메타데이터는 현재 참조 조합을 기준으로 계산하므로 신규 생성 당시 지표와 다를 수 있습니다.

## 8개 후보 → 4게임 축약 휠링

컴포넌트의 **한눈에 → 연구 공식 도구**를 열고 8개 후보번호를 입력한 뒤 **4게임 생성**을 누릅니다.

8개 번호를 네 쌍으로 나누고, 각 쌍을 제외한 6개씩으로 4게임을 구성합니다. 가능한 105개 쌍 분할을 검사해 과거 1등·현재 추천과 충돌하지 않는 분할 하나를 선택합니다. 유효한 분할이 없으면 오류로 종료하며 일부 게임을 삭제하거나 조건을 완화하지 않습니다.

| 후보 8개 안에 포함된 실제 본번호 | 4게임 중 적어도 한 게임의 최소 일치 |
|---|---|
| 3개 | 3개 |
| 4개 | 3개 |
| 5개 | 4개 |
| 6개 | 5개 |

모든 후보 3수 부분집합 `C(8,3)=56`개를 덮습니다. **4게임 전체에만** 조건부 보장이 적용됩니다. 후보 적중과 1등을 보장하지 않습니다. 개별 게임의 1등 확률은 `1/8,145,060`, 서로 다른 4게임의 1등 확률은 `4/8,145,060`입니다.

결과는 미리보기이며 실제 추천·구매·리뷰·자동화 센서에 저장하지 않습니다. 후보 입력이나 통합 선택이 바뀌면 이전 결과와 늦게 도착한 응답을 무효화합니다. 기존 A~E 구매 기록을 덮어쓰지 않습니다.

## 추첨 빈도 진단

같은 도구 영역의 **추첨 빈도 진단**은 현재 공식 이력의 개별 번호 빈도를 읽기 전용으로 검사합니다. 진단은 번호 선택에 사용하지 않습니다.

`E = 회차 수 × 6/45`

`Q = (44/39) × Σ[(관측횟수 − E)²/E]`, 자유도 44.

`44/39`는 회차 내 비복원추출 보정입니다. p값은 점근 카이제곱 기준이며 유한 표본의 정확검정이 아닙니다. 기대횟수 5 미만이면 p값을 표시하지 않습니다. p값은 당첨확률이 아니고 작은 값만으로 조작이나 다음 번호 예측 가능성을 판단할 수 없습니다. 회차 간 독립성과 모든 종류의 편향을 증명하지도 않습니다.

## 근거와 의도적인 제외

- Stern & Cover, Maximum Entropy and the Lottery (1989): https://isl.stanford.edu/~cover/papers/paper91.pdf
- Cushing & Stewart, Applying constraint programming to minimal lottery designs: https://arxiv.org/abs/2307.12430
- 베타-이항 수축의 일반 원리: https://www.bayesrulesbook.com/chapter-3

구매 분포가 없어 최대엔트로피 추정기를 실제 학습한 것처럼 추가하지 않았습니다. 현재 컴포넌트의 균등 추출·조합보정 층화·베이지안 수축을 중복 등록하지 않았습니다. 편향 검정은 진단에만 사용하며 독립된 당첨 예측 공식으로 표시하지 않습니다.

- `python scripts/smoke_research_panel.py`: Playwright 브라우저 6개 시나리오. 로컬 Chromium이 있으면 사용하며 없으면 Playwright 설치 브라우저를 사용합니다.

- 실제 사용자 HA 장비와 미래 추첨 예측 성능을 검증했다는 의미는 아닙니다.
