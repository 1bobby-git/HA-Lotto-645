# v1.11.1 — 최근 추첨 결과의 단색 번호 공

사용자가 제공한 스크린샷을 기준으로 최근 추첨 결과의 번호 표시만 수정했습니다. 추첨 결과 카드의 배경과 정보 배치, 로고, 내 복권 및 추천 리뷰의 번호 칩은 유지합니다.

## 표시 기준

| 번호 범위 | 원 배경색 | 기준 |
|---|---|---|
| 1~10 | `#cd9234` | 제공 이미지에서 추출한 황금색 |
| 11~20 | `#3e63c5` | 제공 이미지에서 추출한 파란색 |
| 21~30 | `#bd4152` | 제공 이미지에서 추출한 붉은색 |
| 31~40 | `#8c8c8c` | 이미지에 없는 범위로, 회색 계열을 단색으로 정리 |
| 41~45 | `#5a9b50` | 제공 이미지에서 추출한 초록색 |

숫자는 흰색·굵기 700으로 중앙 정렬합니다. 넓은 화면에서는 지름 60px, 숫자 24px, 기본 간격 18px입니다. 번호 공의 그라데이션·광택·그림자·테두리는 제거했습니다. `+`는 이미지에서 추출한 `#aeb0b9`를 사용합니다. 보너스 번호에도 같은 번호 범위 색상 규칙을 적용하며 보너스 레이블은 유지합니다.

기존 컨테이너 기반 반응형 크기를 유지하므로 작은 화면에서도 6개 번호와 보너스가 함께 보입니다. 라이트·다크 모드 모두 같은 단색을 사용합니다. 이미지와의 색상 일치를 우선했으며 이 변경으로 접근성 대비 기준 전체를 충족한다고 주장하지 않습니다. 번호와 보너스의 기존 스크린리더 설명 및 고대비 모드 지원 코드는 유지합니다.

## 기능과 업데이트

추천·추첨 결과·QR·저장·센서 로직과 데이터 형식은 수정하지 않았습니다. 운영 화면은 기존 실제 응답을 그대로 사용하며 스크린샷의 회차·번호·금액을 하드코딩하지 않습니다. 날짜·당첨금 영역 추가는 이번 요청 범위에 포함하지 않았습니다.

패널 모듈과 하위 뷰 모듈의 캐시 키를 v1.11.1로 갱신했습니다. 정식 릴리스가 게시되면 HACS에서 v1.11.1로 업데이트하고 Home Assistant를 재시작한 뒤 페이지를 새로 여세요. 이전 화면이 남으면 `Ctrl + Shift + R`로 강력 새로고침하세요. 통합 재등록이나 저장 파일 삭제는 필요하지 않습니다.

## 검증 범위

- 로컬 JavaScript 문법 검사, 기존 승인 시안의 Chromium UI 회귀 77개 항목 통과.
- 번호 스타일 회귀 테스트 4개 추가 및 로컬 통과.
- 로컬 브라우저에서 320·350·390·560·768·870·1100·1440px와 라이트/다크 모드 조합 16개 확인. 단색 배경·흰색 숫자·원형·넘침 없음·구매번호 칩 스타일 보존 확인.
- 번호 범위 경계 1·10·11·20·21·30·31·40·41·45의 분류 확인.
- 저장소의 기존 Validate 및 실제 PNG QR 브라우저 검사는 그대로 유지합니다. 해당 커밋의 실행 결과를 확인한 뒤 병합합니다.

로컬 검증은 테스트 전용 HA 응답을 사용합니다. 사용자의 실행 중인 HA 설치·재시작, 실기기 카메라, Safari와 실제 스크린리더 음성은 이번 로컬 검증 범위가 아닙니다.
