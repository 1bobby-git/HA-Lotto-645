# 연구 기반 추첨 공식 검증 — 1.12.0

## 반영한 자료와 현재 구현의 차이

사용자가 제공한 「HA-Lotto-645 로또 추첨 공식 연구·검증 및 AI추천 공식 설계 보고서」와 「한국 로또 6/45의 공정 추첨을 위한 대표 추첨 공식과 확률·난수성 검증 연구」를 설계 근거로 삼았습니다. 보고서가 설명한 선택번호 중앙값·구간 분포와 달리 실제 기준 버전 1.11.10의 methods.py는 17개의 공식 카탈로그이고, generation.py는 진행률 관리입니다. 실질적인 번호 선택은 analysis.py, AI 번호 반환은 coordinator.py에서 이루어집니다. 보고서의 저장소 설명을 그대로 복사하지 않고 실제 실행 경로를 수정했습니다.

## 공식별 검토 결과

| 구분 | 변경과 판정 |

| 연구의 대표 표본법 | 부분 Fisher–Yates, Floyd, 중복거부, 순차 포함을 실제 선택 가능한 공식으로 추가 |
| 연구 권고 CCSS | 구간별 조합 개수의 정수 누적 가중치로 배분 후 각 구간에서 균등 표본 |
| 보고서 밖 추가 공식 | 조합 인덱스 균등 추첨 + unranking. 조합과 인덱스의 일대일 대응을 전수검증 |
| 베이지안 수축 | 기존 ID 유지. 최근 최대 300회, 사전 강도 500, 빈도 혼합 5%. 최고점 조합 대신 가중 비복원추출 |
| 패턴·빈도·이월·균형 등 | 기존 기능 보존. 균등 생성이나 입증된 예측 공식으로 분류하지 않음 |
| 선택 공식 중앙값 | 1.12.0에서는 내부 점수 중앙값. 1.12.1부터 사용자 요청에 따라 실제 추천번호의 순번별 중앙값 ±1 자동 집계로 변경. 균등·실험 공식도 포함하고 AI·자기 자신은 제외 |

| AI 추천 | 번호는 백엔드 CCSS, AI는 확정된 실행 정보의 설명. 현재 자연어 선호 입력이 없어 공식 선택도 CCSS로 고정 |

생일수 회피 등 ‘비인기 조합’의 국내 효과는 구매 조합별 데이터 없이 확인할 수 없습니다. 검증된 공동당첨 감소나 수익 개선 공식으로 추가하지 않았습니다. 복잡한 새 예측 모델·신경망도 도입하지 않았습니다.

## 균등성의 범위와 호환성

순수 sampler는 모든 유효한 조합에서 균등합니다. 그러나 기존 제품의 과거 1등 조합 제외 정책, 같은 배치 중복 제외, 재생성 직전 조합 제외를 유지하므로 실제 추천은 **허용된 조합 공간에서 조건부 균등**합니다. 홀짝·구간 개수를 강제하는 필터나 점수 최적화를 새 균등 공식 뒤에 붙이지 않습니다. 기존 점수형 공식은 이전부터 비균등한 개인화 경로입니다.

`METHOD_*`, `selected_methods`, 서비스와 엔티티 ID는 보존합니다. 사용자에게 보이는 용어는 추첨 공식으로 통일하고 결과에 `formula_id`, `formula`, `formula_version`을 병행 노출합니다. 과거 저장 기록을 최신 생성 알고리즘으로 소급 주장하지 않습니다.

CSPRNG 번호는 별도 최소 캐시에 저장하며 회차·이력·선택·순번이 같을 때 복원합니다. 이력이 수정되면 캐시를 폐기합니다. 난수 결과를 다시 뽑아 과거 생성시각에 연결하는 업그레이드 복원은 금지합니다.

## 검증과 한계

[정확한 분포 및 회귀 테스트](../tests/test_sampling.py)는 작은 조합 공간에서 난수 분기의 모든 확률을 Fraction으로 합산해 균등성을 확인합니다. 조합 인덱스 역변환, CCSS 가중치 합, 고정번호·범위·중복·제외 공간 소진·생산 CSPRNG 선택·AI 번호 변경 금지·캐시 무효화도 검사합니다.

[검증 스크립트](../scripts/validate_sampling.py)는 각 균등 공식의 실제 코어를 1,000,000회씩, 총 6,000,000회 실행합니다. 고정 seed는 테스트 전용입니다. [실행 결과 JSON](sampling-validation-1.12.0.json)에 난수원, seed, 표본 수, 소스 SHA-256, 번호 빈도·번호쌍·합·적중분포·시계열 요약을 저장합니다. 45개 빈도는 비복원추출 공분산을 고려한 통계량을 점근적 χ²(44)와 비교하고 여섯 주변빈도 검정에는 Holm 보정을 적용합니다.

이 검정은 Monte Carlo로 p-value를 보정한 검정이 아니며 그 차이를 결과에 명시합니다. 번호쌍·적중·시계열은 기술 통계이며 각각 독립 유의성 검정으로 포장하지 않습니다. 실제 한국 추첨의 공정성 인증이나 OS 엔트로피 보안 인증도 아닙니다. 기존 docs/formula-audit-results.json 및 CSV는 이전 버전의 역사적 실험 자료이며, 이번 릴리스의 새 공식 결과로 대체하거나 우위를 주장하지 않습니다. 전체 역사에 대한 새 walk-forward 예측력 우위는 입증하지 않았습니다.

공정·독립 추첨에서 한 게임의 실제 1등 확률은 어떤 공식이든 **1/8,145,060**입니다. 서로 다른 m개 게임의 1등 커버리지는 m/8,145,060이지만 각 티켓의 확률이 개선되는 것은 아닙니다.
