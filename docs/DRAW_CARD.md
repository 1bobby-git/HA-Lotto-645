# v1.11.2 — 흰색 추첨 결과 카드

최근 추첨 결과 카드의 남색 배경을 흰색으로 변경하고, 주변 글자·상태·버튼·구분선의 색상과 작은 글자 가독성을 함께 조정합니다. 번호 공의 단색 배경과 흰색 숫자는 v1.11.1의 사용자 지정 스타일을 유지합니다.

## 색상과 표시

| 영역 | 적용 |
|---|---|
| 결과 카드 | 흰색 `#ffffff`, 옅은 테두리 `#e2e7ef`, 약한 그림자 |
| 회차·대조 결과 | 진한 차콜 `#191f28` |
| 설명·보너스·더하기 기호 | 진한 회청색 `#526073` |
| 공식 확인 | 녹색 `#11684c` / 연녹색 `#eaf7f0` |
| 발표 대기·속보 | 갈색 `#865400` / 연노랑 `#fff4d6` |
| 출처 불일치 | 진한 적색 `#a51d35` / 연분홍 `#fff0f2` |
| 다시 확인 버튼 | 파랑 `#245edb` / 연파랑 `#edf3ff`, hover `#e0eaff` |
| 확인 기준·출처 | 연회색 `#f7f8fa` 바탕, 진한 글자와 파란 링크 |

상태는 색상뿐 아니라 기존 문구와 기호로도 구분합니다. 보너스·상태·출처 설명은 모바일에서도 12px 이상을 유지하고, 결과 다시 확인 버튼은 높이 44px 이상을 사용합니다. 배경만 바꿔 기존의 밝은 글자가 흰색 위에 남는 문제를 방지합니다.

결과 카드는 사용자가 요청한 흰색을 라이트·다크 모드 모두 유지합니다. 전용 `--draw-*` 변수를 카드 내부에만 정의하므로 다른 화면의 HA 다크 모드·로고·내 복권·추천 리뷰·입력 패널은 그대로입니다. OS 강제 색상 모드는 기존 시스템 색상 처리를 유지합니다.

## 범위와 검증

표시용 CSS와 두 단계 모듈 캐시 키, 통합 버전만 변경합니다. 번호·회차·금액을 하드코딩하지 않으며 추천·AI·센서 ID·QR·저장·권한·API와 데이터 처리 함수는 변경하지 않습니다.

- 로컬 JavaScript 문법 검사 통과.
- 기존 Chromium UI 회귀 77개 항목 통과.
- 번호 스타일·새 카드 색상 회귀 19개 항목 통과. 이 중 11개는 일반 텍스트 색상 조합의 대비 계산입니다.
- 320/350/390/560/768/870/1100/1440px × light/dark × 공식/속보/불일치/발표 대기, 총 64개 조합의 흰색 배경·텍스트 대비·넘침 없음·버튼 높이 확인.
- 강제 색상 모드의 키보드 초점 테두리 확인.
- 저장소 Validate의 전체 Python 회귀, HA 옵션·패널 수명주기, Hassfest, 실제 PNG QR 브라우저 검사는 유지합니다. CI 결과는 해당 커밋의 Actions 결과에서 확인합니다.

이번에 조정한 주변 텍스트의 11개 전경·배경 조합은 4.5:1 이상입니다. 이는 [W3C WCAG 대비 최소 기준](https://www.w3.org/TR/WCAG22/#contrast-minimum)을 참고한 부분 검증이며 전체 화면의 접근성 인증을 의미하지 않습니다. 보존한 번호 공의 흰색 숫자와 기존 원색 조합, 다른 화면 전체는 이 대비 통과 주장에 포함하지 않습니다. 예를 들어 황금색 공과 흰색 숫자는 약 2.71:1로 별도의 한계가 남습니다.

로컬 화면은 테스트 데이터입니다. 사용자의 실행 중인 Home Assistant, 물리 카메라·Safari·실제 스크린리더는 이번 로컬 검증 대상이 아닙니다.

## 업데이트
