# 로또 패널 자동 동기화 정책 — v1.11.5

## 무엇이 바뀌었나

이전 패널은 화면이 열려 있는 동안 30초마다 `lotto_645/purchases_get` WebSocket 요청을 보냈습니다. 이 요청은 동행복권이나 GitHub를 직접 조회하는 것은 아니고 Home Assistant 안에 이미 저장된 추첨 결과·구매번호·추천 리뷰 상태를 다시 읽는 동작이었지만, 공식 결과가 확정된 뒤에도 동일한 요청과 화면 갱신이 계속되는 문제가 있었습니다.

v1.11.5부터 **고정 30초 폴링을 사용하지 않습니다.** 화면의 자동 동기화는 상태와 시간에 따라 필요한 경우에만 동작합니다.

## 동작 규칙

| 상황 | 패널 동작 |
|---|---|
| 페이지 최초 진입 | HA 현재 상태를 1회 읽음 |
| 공식 결과가 확정된 일반 시간 | 반복 WebSocket 동기화 중단 |
| 다음 추첨이 남아 있으나 추첨 시간이 아님 | 네트워크 요청 없이 다음 토요일 20:30 KST까지 대기 |
| 토요일 20:30 ~ 일요일 10:30 KST이고 다음 결과가 대기 중 | 60초 간격으로 **HA 내부 상태만** 동기화 |
| 속보·복수 출처 대조·출처 충돌 등 공식 확정 전 | 60초 간격으로 HA 내부 상태 동기화 |
| 화면이 백그라운드/숨김 상태 | 자동 동기화 타이머 중지 |
| 화면을 다시 표시하거나 창에 다시 포커스 | 마지막 동기화 후 15초 이상 지났다면 HA 상태를 1회 동기화 |
| 복권 저장·삭제 | 해당 작업 응답으로 즉시 화면 갱신 |
| `다시 확인` 버튼 | 사용자가 명시적으로 외부 결과 확인을 요청하고 이후 HA 상태 갱신 |

한국 로또 추첨 기준 시간은 KST 고정 오프셋(+09:00)을 사용하며 기기 현지 시간대에 의존하지 않습니다.

## 하단 상태 문구

기존의 `최근 확인 HH:MM · 30초마다 자동 확인` 문구는 제거했습니다.

- 공식 결과가 확정된 경우: `최근 동기화 HH:MM · 공식 결과 확인 완료`
- 추첨 결과를 기다리는 시간대: `최근 동기화 HH:MM · 추첨 결과 대기 · HA 상태 자동 동기화 중`
- 속보를 공식 결과와 대조 중인 경우: `최근 동기화 HH:MM · 공식 대조 대기 · HA 상태 자동 동기화 중`

여기서 **HA 상태 자동 동기화**는 외부 사이트를 직접 조회한다는 뜻이 아닙니다. 외부 결과 확인은 Home Assistant 백엔드의 결과 수집 정책과 사용자가 누른 `다시 확인` 동작이 담당합니다.
