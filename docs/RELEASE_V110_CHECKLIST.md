기능 검증은 Python/Hassfest/HA 설정·저장소·센서/Chromium의 4개 검사로 수행하며 실패 검사를 생략하지 않습니다. 기기·엔티티 저장소를 준비하지 않은 불완전한 테스트 환경으로 발생한 실패를 수정했습니다.

방송 종료 자체를 감지하는 기능 또는 게시 후 10분 이내 수신 보장은 아닙니다. 정해진 발표 시간대에 자동 확인하며, 허용된 출처의 완전한 회차 결과를 수신하면 바로 결과 엔티티를 갱신합니다.

별도 관리권한이 필요한 GitHub main 보호와 원본 이미지 파일 교체 상태는 각 문서에 별도 기록합니다. JSON파일을 저장한 것만으로 보호 적용 완료라고 표시하지 않습니다.
