# 소프트웨어 검증 범위

이 저장소는 추첨 공식의 계산·출력 계약, 실제 추천/구매 기록, 당첨 대조·리뷰, HA 연동을 시험합니다. 과거회차 반복 실행·성능 순위·모의 점수의 저장과 검증은 Lotto Lab의 책임이며 이 저장소에는 그 실행기가 없습니다.

## 필수 검사

- 범위 1~45, 중복 없는 정수 6개, 조건 충돌·탐색 상한, 실제 저장 추천 재현.
- 동일 입력·코어·난수 상태에서 HA 어댑터와 독립 패키지의 결과 동일성.
- 코어에 HA·네트워크·파일 쓰기 의존성 없음, 미래/대상 회차 입력 경계 거부.
- 새 추천 응답, 평일 실시간 알림, 연결 복구·통합 변경·늦은 응답·입력 초안 보존.
- 기존 구매번호·QR·리뷰·사주·센서 수명주기 회귀, 제거 기능 재유입 방지.

## 배포

Python 회귀·독립 코어·실제 HA 설정/패널·Hassfest·브라우저 검사 후 동일 main 커밋을 릴리스합니다. 코어 아카이브·wheel·파일별 SHA256 manifest를 함께 게시합니다. 사용자의 HA/Windows 실기기 설치 결과와 CI 시험 결과는 구분합니다.

계산 구현 검증은 미래 당첨 우월성의 입증이 아닙니다. [코어 API](CORE_API.md) · [실제 추천 리뷰](LOCAL_REVIEWS.md)
