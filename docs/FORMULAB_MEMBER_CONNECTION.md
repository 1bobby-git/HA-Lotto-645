# 로또랩 회원 연결

기본 설치는 계정 없이 자동 연결됩니다. 회원 연결은 선택 사항이며 **통합 구성 옵션 → 로또랩 계정 연결**에서 시작합니다. 표시된 로또랩 주소와 코드를 확인하고, 브라우저에서 기존 계정으로 로그인한 뒤 해당 기기를 승인합니다. HA에는 회원 비밀번호를 저장하지 않습니다.

회원 연결 후에는 서버가 회원 ID에 연결된 일반·유료 JEV 정책을 적용합니다. 클라이언트가 유료 여부를 지정하지 않습니다. JEV가 서버에서 비활성화되어 있거나 운영 키가 없으면 이를 실제 JEV 선정 완료로 표시하지 않습니다. 이메일 신규 가입의 사용 가능 여부는 로또랩의 운영 인증 설정에 따릅니다.

기존 자동 연결에서 전환할 때 저장된 복권·생성 저널·개인화 문맥 키를 보존합니다. 만료된 접근 토큰은 같은 회전 ID로 갱신하고, 갱신 완료 상태를 먼저 저장합니다. 계정에서 기기를 해제했거나 비밀번호를 복구한 경우에는 다시 승인해야 합니다.

2.3.4는 2.3.3의 화면·복권 표시·탭 구조를 유지하면서 이 연결 경로를 추가합니다. 새 브라우저 자원 태그는 캐시 격리를 위한 버전 변경입니다. 컴포넌트 릴리스와 사용 중인 HA에 설치·재시작하는 작업은 구분합니다.

서버 API·계산 Core의 소유 저장소는 `1bobby-git/formulab.kr`이고, 이 저장소는 공개 HACS 클라이언트만 배포합니다. 별도 Lotto-Lab/Core 저장소나 중앙 Account 사이트는 필요하지 않습니다.
