# v1.11.0 — 복권 지갑 UI

승인된 복권 지갑 시안을 적용합니다. 이전의 세로 나열형 페이지와 이전 시안의 `lotto-panel-ui.js`를 사용하지 않습니다.

## 화면

- **한눈에**: 최근 추첨 결과, 공식 확인 상태, 보관한 복권 요약과 간편 등록.
- **내 복권**: 회차별 A~E 보관 번호, 수정과 선택 회차 삭제.
- **추천 리뷰**: 추첨 전 저장한 추천번호 결과와 공식별 누적 평가.
- **복권 등록**: PC 오른쪽 패널 / 모바일 전체 화면에서 QR·사진·직접 입력 → 번호 확인 → 명시적 저장.

키보드 방향키로 화면 탭을 이동할 수 있습니다. 등록 창에서는 초점을 제한하고 닫으면 원래 위치로 돌려줍니다. 다크 모드는 HA 테마를 따릅니다. 자동 갱신은 작성 중인 번호와 revision을 덮어쓰지 않습니다.

## 로고

사용자가 지정한 `custom_components/lotto_645/brand/logo.png`를 기존 로컬 정적 경로로 표시합니다. GitHub 외부 이미지 링크를 사용하지 않습니다. 이미지 재생성·크롭·리사이즈·색상 변경은 하지 않았으며 다크 모드에서도 파일 원본을 유지합니다.

- 크기: 512 × 170px, 5,562바이트
- Git blob SHA: `55ac9df7ae1d37e7def3a9189a51556caa2d6376`

## 유지한 기능과 데이터

추천 알고리즘, AI·사주 설정, 엔티티 ID, 구매번호·리뷰 저장 형식 및 서버 인증은 그대로입니다. 운영 화면에 예시 번호나 가짜 결과를 넣지 않습니다. QR 사진은 번들 `jsQR.js`로 브라우저 안에서 해석합니다. 읽은 QR 문자열의 검증과 번호 저장은 기존 인증된 HA 웹소켓 명령을 이용합니다. 실제 구매나 당첨금 지급을 인증하는 화면은 아닙니다.

## 업데이트

HACS에서 v1.11.0을 설치한 뒤 Home Assistant를 재시작하고 로또 복권 화면을 다시 여세요. 구 화면이 남으면 브라우저에서 `Ctrl + Shift + R`로 강력 새로고침하세요. 기존 통합을 삭제하거나 재등록할 필요는 없습니다. 구매번호 저장 파일은 삭제하지 마세요.

프런트엔드 파일은 `www/lotto-panel.js`, `www/lotto-panel-view.js`, 기존 `www/jsQR.js`입니다. 통합 버전 갱신으로 HA에 등록되는 패널 모듈 URL의 캐시 키도 갱신됩니다.

## 검증

승인된 시안의 두 JS 파일은 패키지와 Git blob SHA까지 동일합니다. 로컬 Chromium에서 시안에 포함된 77개 UI 검증 항목을 재실행했습니다.

저장소의 `python scripts/smoke_ticket_panel.py`는 실제 ES 모듈 로딩, 원본 로고 바이트, 생성한 PNG의 실제 jsQR 디코딩, 명시적 저장, 자동 갱신 중 입력 및 revision 유지, 과거 리뷰 제외 표시, 메뉴, 반응형과 다크 모드를 검증합니다. HA 응답은 테스트 전용 데이터이며 사용자 서버에 연결하지 않습니다. 기존 Validate의 Python 회귀·HA 옵션/패널 수명주기·Hassfest 검사도 유지합니다.

실제 사용자 HA에 설치된 상태, 물리 카메라, iOS/Safari 및 실제 스크린리더 음성은 별도 검증이 필요합니다.
