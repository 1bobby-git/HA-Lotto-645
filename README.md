# 로또 6/45

Home Assistant에서 번호를 생성하고, 구매한 복권과 추첨 결과를 관리합니다. 연결은 자동으로 처리됩니다.

## 한눈에

최근 발표된 당첨번호와 이번 회차에 생성한 번호를 구분해서 보여 줍니다. 이전 회차 번호를 이번 회차 번호로 바꾸어 표시하지 않습니다.

## 추천 리뷰

추첨 전에 저장한 번호는 **추첨 대기** 상태로 등록됩니다. 같은 회차의 결과가 발표되면 자동으로 비교합니다. 결과 발표 전에는 점수·순위·당첨 여부를 매기지 않습니다.

공식별 누적 리뷰는 확인된 결과를 기준으로 합니다. 과거 성적과 별점은 다음 회차의 당첨 가능성을 보장하지 않습니다.

## 내 복권

QR을 카메라나 사진으로 읽거나 번호를 직접 입력할 수 있습니다. 읽은 번호를 확인한 뒤 저장하며, 같은 회차의 복권 여러 장을 구분해서 관리합니다. 저장된 복권은 수정·삭제·내보내기할 수 있습니다.

QR 사진과 구매번호는 외부 계산 서비스로 전송하지 않습니다. 복권 기록은 이 Home Assistant에 보관됩니다. 화면의 등록 기록은 실제 구매·소유권·당첨금 지급을 인증하지 않으므로 원본 복권을 보관하세요.

## 설정

추천 공식, 선택적 AI 설명, 개인화에 필요한 정보, 구매번호를 관리합니다. 개인화에 필요한 출생정보는 별도 동의가 있을 때만 계산에 사용합니다.

연결이 끊겨도 저장된 번호와 복권을 삭제하지 않습니다. 새 번호 생성은 연결이 복구되면 다시 이용할 수 있습니다.
