<h1 align="center">Home Assistant Lotto 6/45 Analysis</h1>

<p align="center">
동행복권 로또 6/45의 1회부터 최신 확정 회차까지 분석하고,<br>
사용자가 선택한 여러 분석 방식별 추천번호 6개와 핵심 근거를 제공하는 Home Assistant 사용자 지정 통합입니다.
</p>

> 로또 추첨은 독립적인 무작위 사건입니다. 이 통합에서 말하는 공개 공식은 빈도·간격·균형·델타·이월수 등 널리 알려진 통계 분석 또는 필터 규칙이며, 실제 당첨을 보장하거나 개별 조합의 1등 확률을 높이는 공식이 아닙니다. 모든 6개 조합의 1등 확률은 `1/8,145,060`으로 같습니다.

## 주요 기능

- 1회부터 최신 회차까지 1등 본번호 전체 분석
- 첫 실행 전체 동기화 후 새 회차만 증분 업데이트
- 선택한 추천 방식마다 번호 6개와 핵심 근거 생성
- 과거 1등 본번호 6개와 완전히 같은 조합 자동 제외
- 추천끼리 같은 번호가 지나치게 반복되지 않도록 조합 다양성 제어
- Home Assistant **AI Task**를 이용한 별도 AI 추천
- 동행복권 통신 장애 시 마지막 정상 캐시 유지
- `즉시 새로고침`, `AI 추천 생성` 버튼과 서비스 제공

## 선택 가능한 추천 방식

`설정 → 기기 및 서비스 → Lotto 6/45 Analysis → 구성`에서 하나 이상을 복수 선택할 수 있습니다. 선택한 방식 수만큼 로컬 추천 센서가 만들어집니다.

| 방식 | 분석 기준 |
|---|---|
| 독창 패턴 ① | 장·단기 빈도 잔차의 반대 위상, 변화 속도, 전이, 번호쌍 그래프 |
| 독창 패턴 ② | 최신 번호의 과거 다음 회차 전이, 미출현 간격, 시간축 곡률 |
| 공개 공식 · 가중 빈도 | 최근 10·30·100회와 전체 빈도를 가중 합산 |
| 공개 공식 · 핫넘버 | 최근 출현 강도가 상승한 번호 중심 |
| 공개 공식 · 콜드·미출현 | 현재 미출현 간격 중심, 극단적 콜드번호 쏠림 제한 |
| 공개 공식 · 동반출현쌍 | 전체 및 최근 120회의 번호쌍 동시출현 잔차 |
| 공개 공식 · 균형 필터 | 번호합, 홀짝, 저·고, 구간 분산 |
| 공개 공식 · 델타 시스템 | 오름차순 번호 간 간격의 크기·반복·전체 범위 |
| 공개 공식 · 이월수 | 직전 회차 번호 1~2개 재등장과 다음 회차 전이 |
| **공식 탐색 ③ · 공개공식 종합형** | 가중 빈도·간격·쌍·균형·델타·이월수의 합의 점수 |

기본 선택은 다음 5개입니다.

1. 독창 패턴 ①
2. 독창 패턴 ②
3. 공개 공식 · 가중 빈도
4. 공개 공식 · 동반출현쌍
5. **공식 탐색 ③ · 공개공식 종합형**

`공식 탐색 ③`은 공개 방식 중 한 요소에 과도하게 맞추는 대신 여러 규칙을 합의 점수로 결합하는 방식을 기본 추천안으로 적용했습니다.

## Home Assistant AI 추천

이 기능은 Home Assistant에 설정된 **데이터 생성 AI Task**를 사용합니다. 외부 AI 키를 이 통합에 따로 저장하지 않습니다.

1. Home Assistant에서 `설정 → AI`를 엽니다.
2. `데이터 생성 작업`에 Google AI Task 등 사용할 AI Task를 지정합니다.
3. Lotto 6/45 Analysis의 `구성`을 엽니다.
4. `Home Assistant AI 추천 사용`을 켭니다.
5. AI Task 엔티티를 비워두면 `설정 → AI`의 기본 데이터 생성 작업을 사용합니다.
6. `AI 추천 생성` 버튼을 누르거나 `lotto_645.generate_ai_recommendation` 서비스를 실행합니다.

AI에는 다음 정보만 요약해 전달합니다.

- 최신 분석 기준 회차
- 위상 변화·다음 회차 전이·번호쌍 그래프 상위번호
- 선택한 로컬 방식별 추천번호와 핵심 근거
- 1~45의 서로 다른 번호 6개, 과거 1등 완전일치 금지 조건

AI 응답은 구조화된 6개 번호로 받은 뒤 다음 검증을 통과해야 센서에 반영됩니다.

- 1~45 범위
- 정확히 6개
- 중복번호 없음
- 과거 실제 1등 조합과 완전일치하지 않음
- 로컬 추천과 완전히 동일하지 않음

검증 실패 시 최대 1회 다시 요청하고, 계속 실패하면 오류 상태를 표시하며 임의의 AI 번호를 저장하지 않습니다.

### 자동 AI 추천

`새 회차 확인 시 AI 추천 자동 생성`을 켜면 새 당첨 회차가 반영된 뒤 AI 추천도 생성합니다. API 사용량이 발생할 수 있으므로 기본값은 꺼짐입니다.

## 설치

### HACS 사용자 지정 저장소

1. HACS를 엽니다.
2. 우측 상단 메뉴에서 `사용자 지정 저장소`를 선택합니다.
3. 저장소 주소에 `https://github.com/1bobby-git/HA-Lotto-645`를 입력합니다.
4. 유형은 `통합`을 선택합니다.
5. `Lotto 6/45 Analysis`를 설치합니다.
6. Home Assistant를 재시작합니다.
7. `설정 → 기기 및 서비스 → 통합 구성 요소 추가`에서 `Lotto 6/45 Analysis`를 추가합니다.

### 수동 설치

`custom_components/lotto_645` 폴더를 Home Assistant의 `/config/custom_components/lotto_645`에 복사한 뒤 Home Assistant를 재시작합니다.

## 생성되는 엔티티

| 엔티티 | 내용 |
|---|---|
| 추천 요약 | 대상 회차, 선택 방식, 전체 추천, 분석 요약, AI 상태 |
| 선택 방식별 추천 센서 | 번호 6개, 핵심 근거, 점수 구성, 강한 번호쌍, 간격 정보 |
| 최신 당첨 결과 | 최신 회차의 본번호, 보너스번호, 1등 정보 |
| Home Assistant AI 추천 | 검증을 통과한 AI 번호와 근거 |
| 즉시 새로고침 | 공식 데이터 즉시 확인 |
| AI 추천 생성 | Home Assistant AI Task를 통한 새 추천 생성 |

예시 상태:

```yaml
state: "1, 17, 28, 32, 33, 40"
attributes:
  method_id: public_ensemble
  label: "공식 탐색 ③ · 공개공식 종합형"
  numbers: [1, 17, 28, 32, 33, 40]
  core_reason: "가중 빈도·미출현·동반출현·균형·델타·이월수의 합의 점수를 적용"
  exact_past_first_prize_match: false
  target_round: 1241
  based_on_round: 1240
  first_prize_odds: "1/8,145,060"
```

위 숫자는 엔티티 구조를 설명하기 위한 예시이며 실제 설치 시 최신 확정 회차 전체 데이터를 기준으로 다시 계산합니다.

## 서비스

### 공식 데이터 새로고침

```yaml
service: lotto_645.refresh
```

### AI 추천 생성

기본 데이터 생성 AI Task 사용:

```yaml
service: lotto_645.generate_ai_recommendation
```

특정 AI Task 엔티티 지정:

```yaml
service: lotto_645.generate_ai_recommendation
data:
  entity_id: ai_task.google_ai_task
```

## 데이터 및 분석 원칙

- 보너스번호는 추천 조합의 점수 계산에서 제외합니다.
- 로컬 추천은 같은 공식 회차와 같은 설정에서 항상 동일하게 생성됩니다.
- 단순 출현빈도 하나만으로 번호를 정하지 않습니다.
- 공개 공식별 결과는 각 규칙의 특징을 비교하기 위한 것입니다.
- 과거 패턴은 미래 추첨 결과를 보장하지 않습니다.
