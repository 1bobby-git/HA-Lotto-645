# HA-Lotto-645 2.0

복권 QR 등록·관리, 비공개 Core API 번호 생성, 실제 추첨 결과 대조·공식 리뷰를 제공하는 Home Assistant 통합입니다.

## 업데이트 전 필수 확인

**2.0부터 새 번호 생성에는 운영 중인 Core API 주소와 기기별 토큰이 필요합니다.** API 연결을 준비하지 않은 1.x 사용자는 v1.21.0을 유지하세요. QR 등록·기존 복권·리뷰 조회는 API 없이도 이용할 수 있습니다. 업데이트 전 HA 백업을 보관하세요.

HACS 사용자 저장소 `https://github.com/1bobby-git/HA-Lotto-645`를 Integration으로 등록하고 버전을 선택합니다. 릴리스는 `lotto_645.zip`을 제공합니다. 설치 후 Home Assistant를 재시작합니다. HACS 기본 목록 등록을 의미하지 않습니다.

## 연결과 기본 기능

구성 → Core 서비스 연결에서 HTTPS 주소, 기기 토큰, 사설 인증서라면 SHA-256 지문을 입력합니다. GitHub 토큰을 입력하지 않습니다. 인증서 검증을 끄지 않으며 토큰은 센서·진단·내보내기에 노출하지 않습니다.

- 공식 선택·공개 조건 설정, 새 번호 생성, 같은 요청 재시도·재조회. 호환 공식은 서비스 카탈로그에서 반영하며 기존 선택에 자동 추가하지 않습니다.
- QR 카메라·사진·주소·직접 입력, 한 회차 여러 장, 수정·삭제·내보내기. QR은 브라우저에서 해석하며 해당 URL을 방문하거나 사진을 서버로 보내지 않습니다.
- 추첨 전 저장 번호와 실제 결과 대조·리뷰. 잠정·충돌·확정·정정을 구분하고 같은 회차를 중복 누적하지 않습니다.
- 실시간 패널 갱신에도 구매 입력 초안·초점을 보존합니다.
- 합의 공식은 서버가 원본 번호로 계산합니다. HA AI는 서버 CCSS 번호를 설명할 뿐 번호를 정하지 않습니다. 설명 실패는 이미 생성한 번호를 삭제하지 않습니다.

명리 원격 계산은 별도 동의가 필요합니다. 기존 개인 입력·복권은 기본적으로 HA 로컬에 보관됩니다. 연결 해제·서버 장애로 로컬 복권을 삭제하지 않습니다.

`lotto_645.refresh`는 명시적 새 생성이며 일반 조회·패널 열기는 생성이 아닙니다. `lotto_645.generate_ai_recommendation`은 서버 CCSS 생성과 선택적 AI 설명입니다. Lab 회원의 일일10회 정책을 기존 HA에 자동 적용하지 않습니다. 실제 기기 한도·속도 제한은 연결 화면에서 확인합니다.

## 구조와 한계

공식 원본은 비공개 Lotto-Lab-Core에서만 관리하고 HA 배포물에는 계산 구현이 없습니다. HA에는 과거 반복 검증·공용 차트·커뮤니티가 없습니다. 웹 제품은 별도 단계입니다.

공정하고 독립적인 추첨의 1등 확률은 한 조합당 1/8,145,060입니다. 과거 성적·근접도 별점은 미래 예측력 인증이 아닙니다. QR 기록은 구매·소유권·당첨금 지급 인증이 아니므로 실제 복권을 보관하세요.
