# 로또 6/45

Home Assistant에서 번호를 생성하고, 구매한 복권과 추첨 결과를 관리합니다.

## 처음 연결할 때

통합을 추가하면 `https://lotto.formulab.kr`에 설치별 고유 자격정보를 만들어 자동 연결합니다. Lotto Lab 계정 로그인, 승인 코드, API 주소·토큰 입력은 필요하지 않습니다.

기존 `lottolab.toiss.kr` 연결은 현재 도메인으로 자동 이동합니다. 이전 회원 승인 방식으로 저장된 연결도 로컬 복권·추천·리뷰와 요청 원장을 보존한 채 자동 연결 방식으로 전환합니다.

연결이 일시적으로 실패하면 저장된 번호와 복권은 그대로 유지하며, 같은 설치 ID와 자격정보로 제한적으로 다시 연결합니다. 공통 비밀키나 비공개 Core는 HA 릴리스에 포함하지 않습니다.

## 한눈에

최근 발표된 당첨번호와 내 복권을 확인합니다. 생성한 번호는 추천 리뷰 메뉴에 모아 표시합니다.

## 추천 리뷰

현재 선택한 공식만 표시합니다. 추첨 전에 저장한 번호는 **추첨 대기** 상태이며, 같은 회차의 당첨번호가 발표되면 자동으로 비교합니다. 결과 발표 전에는 점수·순위·당첨 여부를 매기지 않습니다.

과거 성적과 누적 별점은 다음 회차 당첨 가능성을 보장하지 않습니다. 선택 해제한 공식의 기록은 보존하며 다시 선택하면 볼 수 있습니다.

## 내 복권

QR을 사진이나 카메라로 읽거나 번호를 직접 입력할 수 있습니다. 확인 후 저장하며 같은 회차의 여러 장을 구분해 수정·삭제·내보내기할 수 있습니다.

QR 사진과 구매번호는 외부 계산 서비스로 전송하지 않습니다. Lab 계정에 연결해도 기존 복권을 자동으로 가져가지 않습니다. 화면의 등록 기록은 실제 구매·소유권·당첨금 지급 인증이 아니므로 원본 복권을 보관하세요.

## 설정

추천 공식, 선택적 AI 설명, 개인화에 필요한 정보와 구매번호를 관리합니다. 서비스 연결은 통합이 자동 관리하며 별도 계정 메뉴를 표시하지 않습니다. 출생정보는 별도 동의가 있을 때만 개인화 계산에 사용합니다.

연결이 끊겨도 저장된 번호와 복권은 유지합니다. 새 번호 생성은 연결을 복구한 뒤 이용할 수 있습니다.

## 2.2.2 구매번호 · 공식 일치 표시

같은 회차에 저장한 실제 구매번호와 공식·AI 생성번호 6개가 모두 같으면 Home Assistant 센서와 로또 복권 화면에 구매일치 상태를 표시합니다. 부분 일치는 표시하지 않으며 실제 구매 사실을 인증하는 기능은 아닙니다.

### Formulab 자동 연결

신규 설치는 `lotto.formulab.kr`에 설치별 자격정보로 자동 등록하며 Lotto Lab 로그인·승인 화면을 사용하지 않습니다.
구 `lottolab.toiss.kr` 주소와 임시 회원 연결 상태는 현재 Formulab 구조로 마이그레이션합니다.
기존 추천·구매복권·리뷰·원격 생성 원장은 삭제하지 않습니다.
HACS에서 설치 후 HA를 재시작해야 적용됩니다. 통합을 삭제하거나 다시 등록할 필요는 없습니다.
