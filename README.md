# 로또 6/45

Home Assistant에서 번호를 생성하고, 구매한 복권과 추첨 결과를 관리합니다.

## 처음 연결할 때

통합을 추가하면 Lotto Lab 연결 코드와 승인 링크가 표시됩니다. Lab에 로그인하고 HA의 코드와 같은지 확인해 승인한 뒤, HA에서 연결 확인을 누르면 됩니다. 별도의 접속 주소나 비밀키를 입력하지 않습니다.

Lotto Lab은 현재 초대 회원 테스트 운영 중입니다. 초대 없이 일반 회원가입을 완료할 수는 없습니다. 기존에 운영자가 연결한 기기는 그대로 이용할 수 있으며, 계정 연결은 구성 메뉴에서 진행합니다.

내 계정에서 연결 기기를 해제할 수 있습니다. 계정 복구·비밀번호 변경으로 연결이 해제되면 다시 승인하세요. HA에 저장한 복권과 리뷰는 연결 해제로 삭제되지 않습니다.

## 한눈에

최근 발표된 당첨번호와 내 복권을 확인합니다. 생성한 번호는 추천 리뷰 메뉴에 모아 표시합니다.

## 추천 리뷰

현재 선택한 공식만 표시합니다. 추첨 전에 저장한 번호는 **추첨 대기** 상태이며, 같은 회차의 당첨번호가 발표되면 자동으로 비교합니다. 결과 발표 전에는 점수·순위·당첨 여부를 매기지 않습니다.

과거 성적과 누적 별점은 다음 회차 당첨 가능성을 보장하지 않습니다. 선택 해제한 공식의 기록은 보존하며 다시 선택하면 볼 수 있습니다.

## 내 복권

QR을 사진이나 카메라로 읽거나 번호를 직접 입력할 수 있습니다. 확인 후 저장하며 같은 회차의 여러 장을 구분해 수정·삭제·내보내기할 수 있습니다.

QR 사진과 구매번호는 외부 계산 서비스로 전송하지 않습니다. Lab 계정에 연결해도 기존 복권을 자동으로 가져가지 않습니다. 화면의 등록 기록은 실제 구매·소유권·당첨금 지급 인증이 아니므로 원본 복권을 보관하세요.

## 설정

계정 연결, 추천 공식, 선택적 AI 설명, 개인화에 필요한 정보와 구매번호를 관리합니다. 출생정보는 별도 동의가 있을 때만 개인화 계산에 사용합니다.

연결이 끊겨도 저장된 번호와 복권은 유지합니다. 새 번호 생성은 연결을 복구한 뒤 이용할 수 있습니다.

## 2.1.2 연결·현재 번호 표시

토큰 갱신을 직렬화하고 진행 중인 생성 조회와 원장을 유지합니다.
추천 리뷰 탭의 현재 생성번호는 실제 센서 결과를 표시하며 추첨 전 기록의 사후 리뷰와 분리합니다.
한눈에의 당첨 결과·복권 배치는 유지합니다. 과거 검증은 로또랩 서버에서만 실행합니다.
HACS에서 설치 후 HA를 재시작해야 적용됩니다. 기존 통합·복권·리뷰를 삭제할 필요가 없습니다.
