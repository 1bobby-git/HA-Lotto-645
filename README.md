# HA-Lotto-645

## v1.5.2 · 명리 입력 화면 및 추천 방식 안내 개선

- `Unknown error occurred`가 반복되던 **2단계 Options Flow를 제거**했습니다.
- 이제 `구성` 화면 한 페이지에 **추천 방식 + [명리] 개인 사주정보 + AI + 데이터 소스**가 모두 표시됩니다.
- `명리 권장 · 개인 사주 원국·대운·추첨일`을 선택한 경우에만 [명리] 필수정보 검증을 수행하며, 누락 시 같은 화면에서 어떤 입력이 필요한지 알려줍니다.
- `추천 방식 안내` 센서의 `16`은 점수나 추천번호가 아니라 **지원하는 추천 방식 수**였습니다. v1.5.2부터 상태를 `16개 추천 방식`으로 표시합니다.
- `추천 방식 안내`는 로또 데이터 갱신 실패와 무관한 정적 정보이므로 네트워크/미러 장애 때도 `사용할 수 없음`으로 바뀌지 않습니다.
- 각 추천번호 센서의 속성에 `method_category`, `method_description`을 추가해 해당 방식의 의미를 바로 확인할 수 있습니다.

### 명리 사주정보 입력 위치

```text
설정
→ 기기 및 서비스
→ Lotto 6/45 Analysis
→ 구성
→ 같은 화면의 [명리] 항목에 입력
```

입력 항목은 **양력/음력, 생년월일, 출생시간, 성별, 출생지, IANA 시간대**입니다. 음력 윤달과 선택적인 진태양시(경도+균시차) 보정도 지원합니다. 명리 방식을 선택하지 않았다면 [명리] 항목은 비워도 됩니다.

> 개인 출생정보는 Home Assistant 구성에 로컬 저장되며 공유 로또 미러에 전송되지 않습니다. Home Assistant AI 추천에도 원본 생년월일·출생시간·출생지를 넣지 않습니다.

### 추천 방식 안내 보는 방법

`추천 방식 안내`의 상태는 **지원 방식 개수**입니다. 각 방식의 전체 설명은 엔티티 속성의 `methods`에 저장됩니다. Home Assistant 기본 팝업에서 속성이 접혀 보이면:

```text
개발자 도구 → 상태 → 추천 방식 안내 엔티티 선택
```

에서 `methods` 목록을 확인할 수 있습니다. 또한 실제로 선택한 각 추천번호 엔티티에는 `method_description` 속성이 추가되어 그 방식의 상세 원리를 바로 볼 수 있습니다.

## v1.5.0 · 개인 사주 명리 고도화

`명리 권장 · 개인 사주 원국·대운·추첨일`은 **사주정보 입력 전에는 실행되지 않습니다.** 입력 후 연주·월주·일주·시주, 일간, 오행 강약, 지장간, 십신, 납음, 12운성, 대운을 계산하고 다음 추첨일 20:35의 사주와 천간합·충, 지지합·충·해·형을 비교합니다. 번호는 하도 수리오행에 매핑해 보완오행/십신 역할/대운·추첨일 관계를 주 점수로 사용하고 기존 로또 통계는 보조 점수로만 사용합니다.

> 명리 해석은 전통 문화 체계의 재현 가능한 휴리스틱이며 당첨 확률 상승이 과학적으로 검증된 것은 아닙니다.

Home Assistant용 **로또 6/45 전체 회차 분석 · 선택형 번호 추천 · 명리 추천 · Home Assistant AI 추천** 커스텀 통합입니다.

> 로또 추첨은 독립적인 무작위 사건입니다. 모든 6개 조합의 1등 확률은 동일하게 **1 / 8,145,060**입니다. 이 통합의 통계·명리 방식은 조합 선택용 휴리스틱이며 당첨을 보장하거나 실제 당첨 확률을 높인다고 주장하지 않습니다.

## 수동 재생성

```yaml
action: lotto_645.refresh
```

공유 이력 미러를 확인한 뒤 각 선택 방식의 고득점 후보군에서 **AI를 제외한 추천번호만** 새로 선택합니다. 과거 1등 완전일치 조합은 계속 제외하며 기존 Home Assistant AI 추천은 변경하지 않습니다.

## Home Assistant AI

```yaml
action: lotto_645.generate_ai_recommendation
```

설정 → AI의 기본 데이터 생성 AI 또는 선택한 `ai_task.*` 엔티티를 사용하며, 결과는 번호 범위·중복·과거 1등 완전일치·로컬 추천 완전복제를 다시 검증합니다.
