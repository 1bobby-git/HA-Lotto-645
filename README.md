# HA-Lotto-645

## v1.6.0 · 문서 기반 명리 규칙 및 16종 추천식 검증

개인 사주 추천은 제공된 명리 프롬프트의 지장간 비율·십신10종·통근/투출·격국 후보·억부/조후/통관/병약·운별 합충형파해를 반영합니다. 원문의 잘못된 일진 기준표는 독립 역법 검산값으로 대체하고, 원문 규칙과 자체 점수화의 차이를 기록했습니다.

- [명리 규칙·달력 교정·미적용 범위](docs/SAJU_RULE_AUDIT.md)
- [16종 추천식의 수식/동작 검증](docs/FORMULA_AUDIT.md)
- [실제 이력 기반192게임 점검 원자료](docs/validation-v1.6.0.json)

### 명리 사주정보 입력 위치

```text
설정 → 기기 및 서비스 → Lotto 6/45 Analysis → 구성
→ 명리 사주정보 입력·수정 → 개인정보 저장
→ 다시 구성 → 추천 방식 · AI · 데이터 소스 → 명리 권장 선택
```

양/음력, 생년월일(YYYY-MM-DD), 출생시간(HH:MM), 성별, 출생지, IANA 시간대를 입력합니다. 음력은 **한국 음력** 기준이며 윤달도 확인합니다. v1.5.5의 음력 입력자는 변환 결과를 다시 확인하세요. 진태양시는 선택 사항이며 켜면 경도가 필요합니다. 기존 옵션/엔티티 ID·캐시는 유지됩니다.

명리 추천 센서/프로필의 `natal_evaluation`에는 지장간·강약 근거·격국/보완 후보·십신 분포·설명용 신살이, `luck_layers`에는 대운·세운·월운·일시진의 관계 및 점수가 표시됩니다. `number_ten_gods`와 `number_score_breakdown`에서 각 번호의 실제 근거를 확인합니다.

**수식 검산·코드 테스트 통과는 당첨 예측력이 검증됐다는 의미가 아닙니다.** 점수는 방식 내부의 적합도입니다. 로고/아이콘은 이번 업데이트에서 변경하지 않습니다. 수동 새로고침은 비AI 번호만 다른 고득점 조합으로 바꾸고 AI 결과는 별도로 유지합니다.

> 개인 출생정보와 파생 명리 설명은 HA 내부에서 계산하며 GitHub 미러나 HA AI 프롬프트로 보내지 않습니다.

### 추천 방식 안내 보는 방법

`추천 방식 안내`의 상태는 **지원 방식 개수**입니다. 각 방식의 전체 설명은 엔티티 속성의 `methods`에 저장됩니다. Home Assistant 기본 팝업에서 속성이 접혀 보이면:

```text
개발자 도구 → 상태 → 추천 방식 안내 엔티티 선택
```

에서 `methods` 목록을 확인할 수 있습니다. 또한 실제로 선택한 각 추천번호 엔티티에는 `method_description` 속성이 추가되어 그 방식의 상세 원리를 바로 볼 수 있습니다.

## v1.5.0 · 개인 사주 명리 고도화

`명리 권장 · 개인 사주 원국·대운·추첨일`은 **사주정보 입력 전에는 실행되지 않습니다.** 입력 후 연주·월주·일주·시주, 일간, 오행 강약, 지장간, 십신, 납음, 12운성, 대운을 계산하고 다음 추첨일 20:35의 사주와 천간합·충, 지지합·충·해·형을 비교합니다. 번호는 하도 수리오행에 매핑해 보완오행/십신 역할/대운·추첨일 관계를 주 점수로 사용하고 기존 로또 통계는 보조 점수로만 사용합니다.

> 명리 해석은 전통 문화 체계의 재현 가능한 휴리스틱이며 당첨 확률 상승이 과학적으로 검증된 것은 아닙니다.

Home Assistant용 **로또 6/45 전체 회차 분석 · 선택형 번호 추천 · 명리 추천 · Home Assistant AI 추천** 커스텀 통합입니다.

> 로또 추첨은 독립적인 무작위 사건입니다. 모든 6개 조합의 1등 확률은 동일하게 **1 / 8,145,060**입니다. 이 통합의 통계·명리 방식은 조합 선택용 휴리스틱이며 당첨을 보장하거나 실제 당첨 확률을 높인다고 주장하지 않습니다.

## 수동 재생성

```yaml
action: lotto_645.refresh
```

공유 이력 미러를 확인한 뒤 각 선택 방식의 고득점 후보군에서 **AI를 제외한 추천번호만** 새로 선택합니다. 과거 1등 완전일치 조합은 계속 제외하며 기존 Home Assistant AI 추천은 변경하지 않습니다.

## Home Assistant AI

```yaml
action: lotto_645.generate_ai_recommendation
```

설정 → AI의 기본 데이터 생성 AI 또는 선택한 `ai_task.*` 엔티티를 사용하며, 결과는 번호 범위·중복·과거 1등 완전일치·로컬 추천 완전복제를 다시 검증합니다.
